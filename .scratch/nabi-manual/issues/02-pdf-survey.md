# PDF 원문 실측

Type: research
Status: resolved

## Question

변환을 시작하기 전에 원문 PDF(`/Users/jiwoo/Downloads/NABI_2.5_docs.pdf`, 153쪽)를 숫자로 잰다. `페이지 목록과 slug`, `Callout 종류와 원문 표현`이 이 답을 기다린다.

확인할 것:

- **텍스트 층** — `pdftotext -layout`로 한국어가 제대로 나오는가. 깨지거나 빠지는 글자, 이미지로만 들어간 글이 있는가. 변환을 텍스트 추출로 할 수 있는지, 페이지 이미지를 직접 읽어야 하는지
- **Chapter와 PDF 쪽 대응** — 표지·목차가 몇 쪽이고, 각 Chapter와 1단계 절이 PDF 몇 쪽에서 시작하는가(원문 쪽 번호는 Chapter마다 1부터 다시 시작한다). Chapter 3 목차 전체(`4. 옵션` 다음이 무엇인지)
- **1단계 절별 분량** — PDF 쪽 수, 이미지·스크린샷 수, 표 수
- **주의·경고 표현** — 원문이 주의·경고·참고를 어떻게 적는가(아이콘, 상자, `※`, "주의" 같은 말머리, 색). 종류마다 실제 예와 쪽을 적는다
- **코드·명령어** — 명령어, 경로, 설정값처럼 코드 블록이 될 만한 것이 있는가. 있다면 어떤 언어로 볼 수 있는가
- **머리글·바닥글** — 어떤 글이 반복되는가(지울 대상)

결과는 `.scratch/nabi-manual/research/pdf-survey.md`에 쓴다. PDF 원문을 길게 옮기지 말고, 위치와 짧은 예만 적는다.

## Answer

텍스트 추출로 변환할 수 있다. `pdftotext -layout` 결과에 깨진 글자가 없고, 목차 344개 항목 중 343개가 본문 제목과 일치한다(Ch1 `1.1.`만 목차 "셋팅", 본문 "세팅"). 페이지 이미지는 표, 인라인 아이콘(추출하면 빈칸), 글자 단위 줄바꿈을 이을 때만 본다.

- 표지 PDF 1, 목차 2–11. 본문은 Ch1 PDF 14–27(원문 쪽 +13), Ch2 30–140(+29), Ch3 143–153(+142). Chapter 표지는 12, 28, 141이고 빈 쪽은 13, 29, 142다.
- Ch3 목차는 `4. 옵션`(4.1–4.4, 4.4.1–4.4.2)으로 끝난다.
- Ch2 `3. 편집`은 PDF 49–100, 52쪽이다. 2단계 절 8개의 쪽 범위를 따로 쟀다.
- 주의 표현은 아이콘·색 상자 없이 `※` + 굵은 글씨로 10곳이다. `※ 주의 :` 말머리가 2곳, 빨간 밑줄이 1곳(PDF 19)이다.
- 코드 블록 대상은 없다. 경로·설치 파일명·제어 문자(`//`, `<<`, `/*`)가 인라인 코드 후보다.
- 머리글은 Ch1이 텍스트, Ch2·3은 이미지라 텍스트 층에 없다. Ch2·3 바닥글은 두 줄로 겹쳐 추출된다.
