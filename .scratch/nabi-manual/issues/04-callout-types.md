# Callout 종류와 원문 표현

Type: grilling
Status: resolved
Blocked by: 02

## Question

`PDF 원문 실측`이 찾은 주의·경고·참고 표현을 어떤 `Callout` 종류로 옮길지 정한다.

- `type`을 몇 가지 둘지(`warning`만인가, `note`·`tip`도인가)와 각 종류에 들어가는 원문 표현
- 원문의 말머리(예: "주의", `※`)를 Callout 안에 남길지. 원문 그대로 원칙과 부딪히는지
- 판단이 갈리는 경계 사례 몇 개를 실제 원문으로 정해 둔다

## Answer

원문에는 시각적 구분이 둘뿐이다. `※` + 굵은 글씨(모두 같은 생김새)와 PDF 19 한 곳의 빨간 굵은 밑줄이다. 원문에 없는 분류를 최소로 만드는 쪽으로 정한다.

**`type`은 `warning`과 `danger` 둘이다.** 주의·경고 성격의 `※` 문단만 Callout이 된다. `note`·`tip`은 두지 않는다.

| PDF | 원문 요지 | 옮기는 형태 |
| - | - | - |
| 16 | 부팅하면 반드시 CG를 실행해 보드를 초기화해야 영상이 보인다 | `warning` |
| 18 | 펌웨어 업데이트 메시지가 나오면 진행해야 한다 | `warning` |
| 19 | USB Dongle Lock 분실·파손 시 비용(빨간 굵은 밑줄) | `danger` |
| 36, 41 | `*.nbi`는 폰트·외부 객체를 포함하지 않으니 백업하라(거의 같은 문장, 둘 다 남긴다) | `warning` |
| 75 | 오디오 타임라인 송출 시 Run Setting은 무조건 Manual In이다 | `warning` |
| 108, 134 | `※ 주의 :` | `warning` |
| 26 | `※ **Output Display** :` 용어 설명 | Callout 아님. 원문 표기대로 |
| 27 | `※ 기타 자세한 기술문의는 … ※` 문의 안내 | Callout 아님. 원문 표기대로 |

**Callout 안의 서식**

- `※` 말머리와 문단 전체 굵게는 지운다. Callout이 그 서식을 대신한다. 표를 마크다운 표로 바꾸는 것과 같은 서식 변환이라 원문 그대로 원칙과 부딪히지 않는다. PDF 19의 빨간 밑줄도 `danger`가 대신한다.
- 낱말은 하나도 지우지 않는다. `※ 주의 :`는 `※`만 지우고 `**주의 :**`를 굵게 남긴다. 내어쓰기는 보통 문단으로 푼다.
- 컴포넌트는 아이콘과 색만 넣고 "주의", "경고" 같은 글자 라벨을 넣지 않는다. 원문에 없는 글이 되기 때문이다.
- 문단 중간에 붙은 `※` 문장(PDF 18)은 떼어서 그 문단 바로 뒤에 Callout으로 둔다. 글자와 순서는 그대로다.

**Callout으로 만들지 않는 것** — 원문이 강조하지 않은 곳은 강조하지 않는다. 모두 원문 표기 그대로 본문에 둔다.

- `(관련 옵션 : …)`(PDF 65), `관련 옵션] …`(PDF 68)
- `* ` 보충(PDF 80). `*`은 `\*`로 이스케이프한다
- 말머리 없는 "반드시", "주의하도록 한다" 문장(PDF 14, 16, 70, 117)
- 굵은 질문형 소제목 "정렬선이란?"(PDF 152)
- PDF 50 특수문자 표 안의 `※`
