# PDF 원문 실측

티켓: [02-pdf-survey](../issues/02-pdf-survey.md)

원문은 `/Users/jiwoo/Downloads/NABI_2.5_docs.pdf` 하나다. 이 문서의 모든 주장은 그 PDF를 직접 잰 결과이고, 출처는 PDF 쪽 번호(1부터, 표지 포함)로 적는다. 원문 쪽 번호는 "원문 N쪽"으로 따로 적는다.

측정 도구: `pdfinfo`, `pdffonts`, `pdftotext -layout`, `pdfimages -list`(poppler), 페이지 content stream의 선 그리기 연산자 수, 그리고 표·주의 문구가 있을 만한 쪽은 페이지 이미지를 직접 봤다.

## 요약

- 텍스트 층은 깨끗하다. 변환은 `pdftotext -layout` 추출로 하고, 페이지 이미지는 표·인라인 아이콘·줄 이음 판단이 필요할 때만 본다.
- 표지·목차는 PDF 1–11쪽이고, 본문은 Chapter 1이 PDF 14–27, Chapter 2가 30–140, Chapter 3이 143–153이다.
- 원문 쪽 → PDF 쪽 변환은 Chapter 1이 `+13`, Chapter 2가 `+29`, Chapter 3이 `+142`다.
- 목차 344개 항목 중 343개가 본문 제목과 글자까지 일치한다.
- 코드라 부를 만한 것은 없다. 경로·파일명·제어 문자 정도라 인라인 코드로 충분하다.

## 1. 문서 정보

- Hancom PDF 1.3.0.545로 만들었다(2024-05-07). A4, 153쪽이다. 태그 PDF가 아니어서 제목 구조 정보가 없다.
- 글꼴은 `MalgunGothic`, `MalgunGothicBold`(CID TrueType, ToUnicode 있음) 두 벌과 Type 3 글꼴 하나다. Type 3 글꼴은 Chapter 2·3 쪽 번호에 쓰인 것으로 보인다(아래 머리글·바닥글 참고).
- 암호화가 없고, `pdftotext`가 경고 한 줄(`Syntax Warning: Illegal annotation destination`) 외에는 문제없이 끝난다.

## 2. 텍스트 층

**결론: 텍스트 추출로 변환할 수 있다.** 단, 아래 네 가지는 페이지 이미지를 함께 봐야 한다.

- **글자 깨짐 없음.** 추출 결과에 replacement 문자(U+FFFD)나 PUA 문자가 하나도 없다. 비한글 문자는 `·`(목차 점선), `「」`, `①②③`, `㉠㉡`, `ⓐⓑ`, `※`, `▶■` 같은 정상 기호뿐이다.
- **이미지로만 들어간 본문 없음.** 모든 본문 쪽에 텍스트가 있다. 글이 거의 없는 쪽(PDF 81, 128 등)은 스크린샷이 쪽을 채운 경우다. 다만 스크린샷 안의 글(대화상자 문구, PDF 24의 VLC 다운로드 안내 등)은 텍스트 층에 없다.
- **인라인 아이콘이 빈칸으로 빠진다.** 본문 문장 속에 작은 아이콘 이미지가 들어간 곳은 추출하면 공백만 남는다. 예: PDF 63 "위치 고정(      )된 편집", PDF 53 "아이콘(        )을 선택한 후", PDF 134 `Seek`·`OnAir` 버튼 그림. 60px 미만 작은 이미지가 약 160개로, 대부분 이런 인라인 아이콘이나 표 안 아이콘이다(절별 수는 4절 표의 "작은 이미지" 열).
- **줄바꿈이 글자 단위다.** 한글이 낱말 중간에서 끊긴다(예: PDF 14 "슬 / 롯이"). 한글로 끝나고 한글로 시작하는 줄 경계가 본문 전체에 약 730곳이다. 줄 끝 공백이 남지 않으므로 원래 띄어쓰기가 있었는지 텍스트만으로는 알 수 없다. 이을 때 붙일지 띄울지는 문맥으로 정하고, 애매하면 페이지 이미지를 본다.
- **경로의 `₩`는 텍스트 층에서 `\`다.** 맑은 고딕이 백슬래시를 `₩`로 그릴 뿐이다(PDF 80, 147). PDF 127 단축키 표의 "상단 숫자 키 ₩"도 텍스트는 `\`다.

## 5. 주의·경고 표현

전용 아이콘이나 색 상자는 없다. 모두 `※` 말머리와 굵은 글씨로 표현하고, 한 곳만 빨간색 밑줄을 더한다. "참고", "Tip", "Note", "경고" 말머리는 본문에 없다("경고"는 제목에만 나온다).

| 종류 | 생김새 | 예(PDF 쪽) |
| - | - | - |
| `※` + 굵은 문단 | 들여쓴 별도 문단, 전체 굵게 | PDF 16 "※ 천하통일 HD200은 Overlay로 연결되기 때문에…", PDF 36 "※ *.nbi 파일은 함께 사용된 폰트나…" |
| `※` + 굵은 문장(문단 안) | 문단 끝에 이어 붙음 | PDF 18 "※ 드라이버 설치 진행 중 펌웨어 업데이트 메시지가…" |
