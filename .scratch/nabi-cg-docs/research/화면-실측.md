2차로 처리할 수 있지만, **틀린 값은 조용히 배포된다.**

`지금 저장소가 쓰는 말` 칸은 이미 커밋된 본문에서 뽑아 둔 것이다 — **비교 대상이지 정답이
아니다.** 화면이 다르면 화면이 이긴다.

## 1. 옵션창 한글 이름 — `01a` 어디서나

## 2. 값 12칸 — `01a` 어디서나

**게이트 2·3이 이걸 요구한다.** 값 파일 한 곳이 단일 출처가 되고 본문에는 토큰만 들어간다 —
숫자를 본문에 직접 박으면 폰트를 바꾸는 날 두 페이지가 동시에 낡는다.

**값마다 출처 파일과 확인일을 단다.** 재확인이 「기억을 뒤지는 일」이 아니라 **「파일 하나 여는
일」**이 되는 것이 그 한 줄의 값이다.

| 대상 | Height | Width | Kerning | Leading | 출처 파일 | 확인일 |
|---|---|---|---|---|---|---|
| 설교 자막 | | | | | | |
| 광고 자막 | | | | | | |
| 설교 자막 배경판 | | | — | — | | |
| 광고 하단바 | | | — | — | | |

출처 파일은 실제로 연 파일 이름을 그대로 적는다 — `2026-08-03 설교자막.카사` 처럼.

## 3. `[화면]` 구멍 — `01b` 방송실

**매뉴얼이 침묵하는데 화면에 있는 것.** 나머지 네 태그가 *"매뉴얼이 말한 것"* 아니면 *"우리가
말한 것"*인데 이건 **compix 제품이 말하는데 매뉴얼엔 없는 것**이다.

여기 적는 줄이 그대로 `[화면 2026.02]` 태그가 되고 게이트 5가 지킨다 — 다음에 PC를 업데이트하면
**이 줄들이 전부 한꺼번에 터지고** 하나씩 다시 봐야 통과한다. 그래서 **10줄 내외로 끝낸다.**

### §6.1 Playback (2024.09)

| 확인할 것 | 화면에서 본 것 |
|---|---|
| `GA` / `S1` / `S2` 토글 — 각각 무엇을 In/Out 하는가 | |
| `Stop All` 버튼 — 누르면 무엇이 멈추는가 | |

### §6.2 Run Setting (2024.06 · 2024.09)

**매뉴얼이 6개, 화면이 7개로 이미 어긋나 있다. 화면이 이긴다.**

| 확인할 것 | 화면에서 본 것 |
|---|---|
| **모드가 실제로 몇 개인가** — 이름을 전부 | |
| `All File Playback` — 송출 중 파일 변경 모드가 맞나 | |
| `Edit Sync` — `All File Playback`일 때만 활성화되나 | |
| Global Playback 보기 설정 콤보박스 — 무엇을 고르는가 | |

### §7 단축키 (2024.06 · 2026.02)

매뉴얼 치트시트에 **없는** 세 개다.

| 단축키 | History가 말하는 것 | 화면에서 본 이름·동작 |
