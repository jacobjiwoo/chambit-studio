# 07 — 본문: 도형 속성

**What to build:** `도형 속성` 페이지가 열린다 — 자막 배경판·하단바 크기를 손댈 때 여는
페이지이고, **우리 기준값이 그 자리에 숫자로** 있고, 아직 화면에서 확인 못 한 문장에는
「확인 전」 배지가 붙어 있다.

원본 `Ch2 §4.3` 3페이지. **`Custom 도형`은 2차로 내린다** — *"곡선 조절은 손으로 끌어보면서
익히는 것이라 문장으로는 감이 안 온다."*

**Blocked by:** 03 — 값 파일 + 토큰 치환 (설교 자막 배경판·광고 하단바 4칸이 이 페이지에
들어간다) · 04 — 사이드카 + 배지.

**Status:** ready-for-agent

## 이식할 것이 이미 있다

프로토타입 43(`prototypes/43-도형속성-글로만.md`)이 이 페이지를 그림 0장으로 이미 썼다.
**원본 그림 19장 중 16장이 표 한 줄씩으로 끝났다 — 이름이 곧 모양이라서다**(`Framed`가 붙으면
테두리 도형). 이 티켓은 이식 + 태그 달기 + 토큰 꽂기다.

프로토타입이 쓸 때는 사이드카도 값 파일도 없었다. **문장마다 태그를 새로 판정해야 하고**,
그 판정이 이 티켓의 실제 일이다 — 어느 문장이 `[원본 p.NN]`이고 어느 문장이 지어낸
`[추론]`인지 PDF와 대조해 가른다.

- [ ] 기본형 슬롯 다섯이 다 있다 (`H1 + 한 줄` / `어디서 여는가` / `H2 작업들` / `H2 나머지 속성` / `H2 관련`)
- [ ] 페이지 안쪽 H2가 **작업**으로 갈려 있다 — 기능 이름 나열이 아니다
- [ ] 배경판·하단바 값이 토큰으로 들어가 숫자로 렌더된다
- [ ] 문장마다 태그가 붙어 있고 `[추론]` 문장에 배지가 뜬다
- [ ] `[원본 p.NN]`의 페이지 번호가 실제 PDF 위치와 맞는다
- [ ] 첫 등장 병기가 필수로 들어갔다
- [ ] 아이콘을 **생김새가 아니라 경로로** 가리킨다 — 단축키가 있으면 단축키, 메뉴가 있으면 메뉴 경로
- [ ] `Custom 도형`이 이 페이지에 없다

- [ ] 그림이 0장이다
