# 07 — 본문: 도형 속성

**What to build:** `도형 속성` 페이지가 열린다 — 자막 배경판·하단바 크기를 손댈 때 여는
페이지이고, **우리 기준값이 그 자리에 숫자로** 있고, 아직 화면에서 확인 못 한 문장에는
「확인 전」 배지가 붙어 있다.

원본 `Ch2 §4.3` 3페이지. **`Custom 도형`은 2차로 내린다** — *"곡선 조절은 손으로 끌어보면서
익히는 것이라 문장으로는 감이 안 온다."*

**Blocked by:** 03 — 값 파일 + 토큰 치환 (설교 자막 배경판·광고 하단바 4칸이 이 페이지에
들어간다) · 04 — 사이드카 + 배지.

**Status:** ready-for-human

## 이식할 것이 이미 있다

프로토타입 43(`prototypes/43-도형속성-글로만.md`)이 이 페이지를 그림 0장으로 이미 썼다.
**원본 그림 19장 중 16장이 표 한 줄씩으로 끝났다 — 이름이 곧 모양이라서다**(`Framed`가 붙으면
테두리 도형). 이 티켓은 이식 + 태그 달기 + 토큰 꽂기다.

프로토타입이 쓸 때는 사이드카도 값 파일도 없었다. **문장마다 태그를 새로 판정해야 하고**,
그 판정이 이 티켓의 실제 일이다 — 어느 문장이 `[원본 p.NN]`이고 어느 문장이 지어낸
`[추론]`인지 PDF와 대조해 가른다.

- [x] 기본형 슬롯 다섯이 다 있다 (`H1 + 한 줄` / `어디서 여는가` / `H2 작업들` / `H2 나머지 속성` / `H2 관련`)
- [x] 페이지 안쪽 H2가 **작업**으로 갈려 있다 — 기능 이름 나열이 아니다
- [ ] 배경판·하단바 값이 토큰으로 들어가 숫자로 렌더된다 — **03으로 넘긴다** (§남은 것)
- [x] 문장마다 태그가 붙어 있고 `[추론]` 문장에 배지가 뜬다
- [x] `[원본 p.NN]`의 페이지 번호가 실제 PDF 위치와 맞는다
- [x] 첫 등장 병기가 필수로 들어갔다
- [x] 아이콘을 **생김새가 아니라 경로로** 가리킨다 — 단축키가 있으면 단축키, 메뉴가 있으면 메뉴 경로
- [x] `Custom 도형`이 이 페이지에 없다
- [x] `H2 관련`에서 글자 속성으로 가는 링크가 있다 — 크기 조절이 글자↔도형을 넘나든다
- [x] 그림이 0장이다
- [x] 05의 재현율 게이트가 통과한다 — 풀어 쓰다 검색 키를 흘리지 않았다

## 남은 것 — 기준값 블록 하나

`_values`도 토큰 치환기도 아직 없다(03 미착수). 그 입력인 값 4칸(설교 자막 배경판 `Height`·
`Width` / 광고 하단바 `Height`·`Width`)도 01이 방송실 PC 앞에서 받아 적어야 나온다.

**그래서 이 페이지는 기준값 블록 없이 열었다.** 나머지 열 항목은 그 블록과 독립이고, 03이
붙는 날 `## 자막이 길어져 배경판을 늘려야 할 때` 아래 `### 1.`에 인용 블록 한 개가 들어간다 —
본문 문장은 손댈 것이 없다.

## 원본 페이지 번호 — 프로토타입 43의 정정을 다시 정정한다

프로토타입 43은 `Ch2 §4.3`을 **p.109–111**로 적고 그것이 `research/manual-toc.md`(p.108–110)의
정정이라고 했는데, **둘 다 인쇄 번호가 아니다.** 실제 인쇄 번호는 **p.80–83**이고 109–111은
그 PDF 쪽 번호다(Ch2는 인쇄 번호 +29). 나머지 태그(`[원본 p.74]`…)가 전부 인쇄 번호라
그대로 뒀으면 검수자가 자를 두 개 들고 다녔을 것이다. 자는 **인쇄 번호 하나**다.

이 페이지가 인용하는 자리 — §4.3 도형 객체 속성(p.80–83) · §4.5 Color(p.89–92) ·
§7.2 편집 단축키(p.108). `build-docs.test.ts`가 사이드카의 `원본` 태그를 이 세 구간으로 가둔다.

**태그가 가리키는 자리는 「그 절」이 아니라 「그 문장이 실제로 있는 쪽」이다.** `Flip Vert / Horz`가
글자·이미지 객체와 같은 동작이라는 것은 도형 절(p.83)이 아니라 이미지 절(p.89)이 적어 뒀고,
그래서 `[원본 p.89]`다. `Framed`가 붙으면 테두리 도형이라는 **규칙**은 매뉴얼에 문장으로 없다 —
p.80의 그림 여덟 장을 나란히 놓고 우리가 읽은 것이라 `[추론]`이다.
