# 10 — 본문: 단축키 (치트시트형)

**What to build:** `단축키` 페이지가 **표 그대로 한 장**으로 열린다. 훑어 내려가며 찾는
치트시트이므로 쪼개지 않는다. 원본 `Ch2 §7` 전체 5페이지.

**성격을 다시 적어 둔다** — 실측하니 `§7.5 송출`은 **키패드 5개뿐**이고 나머지 전부가
파일·편집·보기·삽입이다. 이건 *"방송 중 치트시트"*가 아니라 **편집 치트시트**다.

**Blocked by:** 01 — 방송실 PC 실측 (누락 단축키 3개의 실제 이름과 동작) · 04 — 사이드카 +
배지 · 06 — 버전 추적 (누락 3개가 `[화면 YYYY.MM]` 태그로 들어가고 게이트 5가 이걸 지킨다).

**Status:** ready-for-agent

## 치트시트형은 슬롯이 다르다

기본형이 아니다. **표 그대로**이고 `Icon` 열은 삭제한다 — 30×30 아이콘 24개는 자체 캡처가
원본과 거리를 못 벌어주는 유일한 자산군이라 전부 뺀다.

## 매뉴얼이 짧은 자리

`§7`은 독자가 **전체 목록으로 읽는** 곳이라 **낡음이 가장 위험한 두 자리 중 하나**다. 매뉴얼이
2024-05 이후 갱신되지 않는 동안 소프트웨어가 6번 바뀌었고, 최소 셋이 빠져 있다.

| 단축키 | 출처 |
|---|---|
| `Ctrl+Shift+F5` | Reset Layout |
| `Ctrl+Shift+F9` | Playback Resource Browser |
| `Ctrl+Shift+F8` | File Browser (2026.02, 창 › File Browser) |

셋은 **매뉴얼에 없고 화면에만 있으므로** `[화면 YYYY.MM]` 태그를 단다. 다음에 방송실 PC를
업데이트하면 게이트 5가 이 셋을 터뜨리고 다시 확인하게 만든다.

- [ ] 표 한 장이다 — 쪼개지지 않았고 클릭 한 번에 열린다
- [ ] `Icon` 열이 없다
- [ ] 누락 단축키 3개가 실제 이름·동작과 함께 표에 있다
- [ ] 그 셋에 `[화면 YYYY.MM]` 태그가 붙어 있고 날짜가 `NABI_BUILD`와 같다
- [ ] 게이트 5가 통과한다 — 상수를 올리면 이 셋이 터진다
- [ ] `Ctrl+H`로 검색했을 때 이 페이지가 나온다
- [ ] 사이드바에서 다른 항목의 하위가 아니라 **같은 층위**에 서 있다
- [ ] 그림이 0장이다
