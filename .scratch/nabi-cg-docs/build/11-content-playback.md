# 11 — 본문: 송출 §6 (검수가 출시를 막는 유일한 섹션)

**What to build:** `송출` 페이지가 열린다. 원본 `Ch2 §6.1·6.2·6.3·6.5` 4페이지
(`6.4 Global Animation` 제외 — ㉢·㉣에 **원본에 이름이 아예 없다**).

**여기만 검수가 출시를 막는다.** `Clear : 송출 정지 후 남은 화면 지움`이 틀리면 **생방송 중
화면이 날아간다.** 편집 중 실수는 되돌리면 그만이지만 이건 아니다. 나머지 6개는 `[추론]` 배지를
단 채로 열지만 이 페이지는 **나비CG에서 `In`/`Out`/`Clear`/`Skip`을 실제로 눌러 확인한 뒤에만**
연다.

**Blocked by:** 01 — 방송실 PC 실측 (`§6.1` 토글·버튼, `§6.2` 모드·옵션) · 04 — 사이드카 +
배지 · 06 — 버전 추적 (`[화면]` 태그가 여기 가장 많이 붙는다).

**Status:** ready-for-agent

## 지금 이미 낡아 있는 자리

매뉴얼이 2024-05 이후 갱신되지 않는 동안 이 섹션에서만 셋이 바뀌었다.

| 자리 | 채울 것 | 언제 |
|---|---|---|
| `§6.1 Playback` | `GA`/`S1`/`S2` 토글, `Stop All` 버튼 | 2024.09 |
| `§6.2 Run Setting` | `All File Playback` 모드, `Edit Sync` 옵션, Global Playback 보기 설정 콤보박스 | 2024.06·09 |

**`§6.2`의 모드는 매뉴얼이 6개, 화면이 7개다.** 매뉴얼이 골격이고 화면이 구멍을 메우되
**어긋나면 화면이 이긴다.** `6.2.1`은 독자가 **전체 목록으로 읽는** 자리라 열거가 짧아지는 것이
그대로 오류가 된다.

## 게이트는 일정의 문제이지 화면의 문제가 아니다

*"준비 중"* 항목을 띄우는 장치를 짓지 않는다. 검수가 끝나기 전에는 이 페이지가 사이드바에
**제목만** 서 있고(2차 자리와 같은 형태), 검수가 끝나면 본문이 들어간다. 출시 전에 §6을 확인해
버리는 쪽이 싸다.

## 화면에서 실제로 눌러 확인할 것

- `In` / `Out` / `Clear` / `Skip`이 각각 무엇을 하는가 — 특히 `Clear`가 무엇까지 지우는가
- `§6.5`의 진짜 경로는 툴바 아이콘이 아니라 `Ctrl+Enter(키패드)`다
- `§6.1` 토글 셋과 `Stop All`
- `§6.2` 모드 개수와 이름

- [ ] `In`/`Out`/`Clear`/`Skip`을 나비CG에서 실제로 확인한 뒤 문장을 썼다
- [ ] `§6.1`의 토글 셋과 `Stop All`이 본문에 있고 `[화면 YYYY.MM]` 태그가 붙어 있다
- [ ] `§6.2`의 모드가 **화면에서 센 개수**대로 전부 열거돼 있다
- [ ] `All File Playback` · `Edit Sync` · Global Playback 보기 설정이 본문에 있다
- [ ] `[화면]` 태그의 날짜가 전부 `NABI_BUILD`와 같다 — 게이트 5가 통과한다
- [ ] `6.4 Global Animation`이 이 페이지에 없다
- [ ] 아이콘을 경로로 가리킨다 — *"빨간 OnAir 버튼"* 같은 문장이 없다
- [ ] 문장마다 태그가 붙어 있고 검수를 못 거친 `[추론]` 문장이 **0개**다
- [ ] 기본형 슬롯 다섯이 다 있다
- [ ] 그림이 0장이다
- [ ] 05의 재현율 게이트가 통과한다
