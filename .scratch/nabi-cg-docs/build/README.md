# 구현 티켓 — 나비CG 문서 사이트

[`../spec.md`](../spec.md)를 tracer bullet 12개로 쪼갠 것이다. 결정 티켓(웨이파인딩)은
[`../issues/`](../issues/)에 있고 여기 있는 것은 **구현** 티켓이다.

의존 순서대로 번호가 붙어 있다. 어느 시점이든 **blocker가 전부 끝난 티켓**(frontier)을 잡는다.

```
01a 값·이름 ── 03 값·토큰 ── (07 · 08 · 09의 값 블록)
01b 화면구멍 ─────────────── 10 · 11

02 뼈대 ──┬── 04 사이드카 ──┬── 06 버전 ── 10 · 11
          │                 └──────────── 07 · 08 · 09
          └── 05 검색 ───────────────────── 12 안내문
```

**01이 두 쪽으로 쪼개졌다**(2026-08-06). 방송실이 실제로 필요한 것은 `01b`뿐이고, 한글 이름은
애초에 블로커가 아니었다 — **08·09는 01·03을 안 기다린다.** 07이 값 블록을 비운 채 나간 것과
같은 방식으로, 값과 이름 대조는 **열린 칸**으로 남는다. 근거 전문은
[01 §쪼갠 이유](01-field-measurement.md).

**`ready-for-human`은 본문이 안 열렸다는 뜻이 아니다.** 07은 페이지가 떠 있고 열한 항목 중
열이 닫혔다. 남은 하나가 **기준값 블록**이고 그 입력(값 4칸)이 `01a`에서 나온다 — 07이 아니라
01a·03이 움직여야 닫힌다. **08·09도 같은 모양으로 끝난다**(본문은 열고 값 블록·이름 대조는
열린 칸으로 남긴다).

## 사람이 해야 하는 것 — 이제 `01b` 하나다

`01a`(값 12칸·한글 이름)는 자막 파일 하나 열 수 있는 곳이면 어디서나 되고, **`01b`만 방송실 PC
앞에 앉아야 한다.** 그리고 `01b`를 기다리는 것은 10·11 둘뿐이다.

**02가 01을 안 기다렸던 이유가 08·09에도 그대로 걸린다.** 글자 속성 용어는 매뉴얼 병기 28종에
이미 있었고, `Style Catalog` 계열은 이름이 없지만 **게이트 1이 `스타일` 질의로 막는다.** 코드와
현장 작업이 병렬로 간다.

**11(송출)만 검수가 출시를 막고, 하필 거기가 매뉴얼이 이미 낡은 자리다** — `01b` 없이는 열 수
없다. 나머지 6개 섹션은 `[추론]` 배지를 단 채로 연다.

## 본문 티켓 공통 규칙 (07–11)

페이지마다 다시 적지 않는다. 다섯 티켓 전부에 걸린다.

**템플릿 3형** — 기본형(5개 페이지) / 치트시트형(단축키) / 트러블슈팅형(2차). 기본형 슬롯은
`H1 기능 이름 + 해주는 일 한 줄` / `어디서 여는가` / `H2 작업들` / `H2 나머지 속성`(레퍼런스 표) /
`H2 관련`. **비어 있는 필수 슬롯이 곧 검수 표시다.**

**본문 규칙 넷**

1. **첫 등장 병기가 필수다** — `Kerning(자간)` `Style Catalog(서식 모음)`. 화면의 영문과
   머릿속 한글이 **둘 다 색인에 들어간다**
2. **아이콘은 생김새가 아니라 경로로 가리킨다** — 단축키가 있으면 단축키, 메뉴가 있으면 메뉴
   경로. *"빨간 OnAir 버튼"* 같은 문장은 **PDF에서 나오지 않으므로** 쓰지 않는다. **경로도
   이름도 없는 자리는 2차로 내리고 그림을 부르지 않는다**
3. **그림 0장**
4. **별칭 목록 슬롯을 두지 않는다** — `줄간격`/`줄 간격` 변형은 토크나이저가 흡수한다

**페이지 안쪽은 작업으로 가른다** — *"자막이 한 줄에 안 들어갈 때"*. 기능 이름만 나열된 목록은
이미 매뉴얼에 있다. 여러 방법이 있으면 **손대는 순서**를 번호로 붙인다.

**문장마다 사이드카 태그를 판정한다.** `[원본 p.NN]` / `[추론]` / `[운영 지식 필요]` /
`[운영]` / `[화면 YYYY.MM]`. 검수자는 원본에 안 묶인 것만 본다.

**문법 — 문장 끝에 공백 없이 바로 붙인다:** `문장이다.[추론]`. `buildDocs()`(04)가 이 한 줄로
사이드카를 걷고 본문에서 지운다 — 대괄호 뒤에 `(...)`가 없으면 마크다운이 링크로 안 읽으므로
이스케이프가 따로 필요 없다.

**우리 숫자는 본문에 직접 박지 않는다** — 토큰으로 두고 값 파일이 단일 출처다.

**써 놓고 05의 재현율 게이트를 돌린다.** 사람이 읽기 좋게 풀어 쓰다가 색인을 깎는 사고가
실제로 두 번 재현됐다 — 프로토타입 42에 `자간`이 0회, 검색 시안에서 `줄간격`·`스타일` 각 0건.
