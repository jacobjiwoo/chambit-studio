# 08 — 본문: 텍스트 임포트 + Style Catalog

**What to build:** 두 페이지가 열린다.

- **텍스트 임포트** (`Ch2 §3.6.5`, 5p) — 원고 txt를 자막으로 들여오는 페이지. **여기서
  물려받은 사람이 자막 추출기가 있다는 사실을 처음 안다.**
- **Style Catalog** (`Ch2 §3.4`, 3p) — 서식을 모아 두고 재사용하는 페이지. **`스타일`로
  검색했을 때 걸리는 페이지가 여기다.**

**Blocked by:** 04 — 사이드카 + 배지 (**충족됨**).

~~01 — 방송실 PC 실측~~ · ~~03 — 값 파일 + 토큰 치환~~ → **07과 같은 방식으로 미룬다.**
07이 값 블록 한 칸을 비운 채 열한 칸 중 열을 닫고 나갔고, 여기도 같다 — 지금 쓰고, 화면 한글
이름 대조와 값 블록은 **열린 칸으로 남겨** 01a·03이 왔을 때 꽂는다. 이름은 우리가 짓되
게이트 1이 절반을 막는다(`스타일` 질의가 하드코딩돼 있어 그 낱말이 본문에 없으면 빌드가
터진다). 틀렸을 때 비용은 find-replace 한 번과 질의 세트 한 줄이다. 근거 전문은 01 §쪼갠 이유.

**Status:** ready-for-agent

## 두 페이지가 한 티켓인 이유

둘 다 **이름만으로는 뭔지 알 수 없는 기능**이고, 둘 다 `[운영]` 문장이 본문의 핵심이며, 둘 다
01의 한글 이름 판정에 걸린다. 합쳐 8페이지로 한 컨텍스트에 들어간다.

## 자막 추출기를 가리키는 한 줄

`§3.6.5`를 1차로 올린 **유일한 근거**인데 지금까지 문서 어디에도 없었다. 본문 한 줄 +
`/subtitle-extractor` 링크가 들어가고 사이드카 `[운영]`으로 등록된다. **반대 방향(도구 → 문서)은
안 잇는다.**

## `스타일` 질의가 여기 걸린다

검색 시안에서 `스타일` 질의가 **0건**이었고 원인은 색인이 아니라 **본문**이었다 —
`Style Catalog`에 한글 이름이 없어 색인에 한글이 아예 안 들어갔다. 이 페이지가 그 이름을
확정하고, 05의 게이트가 그 순간부터 이 질의를 지킨다.

- [ ] 두 페이지 다 기본형 슬롯 다섯을 갖췄다
- [ ] 페이지 안쪽 H2가 **작업**으로 갈려 있다
- [ ] `Style Catalog`의 한글 이름이 첫 등장 병기로 본문에 있다 — **우리가 짓는다**
- [ ] `Char Unit`도 같은 방식으로 이름이 붙었다 (`Take In`은 11의 몫이다)
- [ ] **화면 한글 이름 대조 — `01a`로 미룬다.** 화면에 compix가 지어 둔 한글이 있으면 그걸로 갈고 05의 질의 세트를 같이 고친다. 07의 값 블록과 같은 자리이고, **이 칸이 닫히기 전에는 `ready-for-human`이다**
- [ ] **기준값 블록 — `03`으로 미룬다** (해당 값이 있으면)
- [ ] 텍스트 임포트 본문에 자막 추출기를 가리키는 한 줄과 `/subtitle-extractor` 링크가 있다
- [ ] 그 한 줄이 사이드카에 `[운영]`으로 등록돼 있다
- [ ] 문장마다 태그가 붙어 있고 `[추론]` 문장에 배지가 뜬다
- [ ] 아이콘을 경로로 가리킨다 — 경로도 이름도 없는 자리는 **쓰지 않고 2차로 내린다**
- [ ] 그림이 0장이다
- [ ] **`스타일` 질의가 Style Catalog 페이지를 반환한다** — 05의 게이트가 통과한다
