# 05 — 검색: 색인 굽기 + `Ctrl+K` 모달 (게이트 1)

**What to build:** 나비CG 화면에 보이는 단어를 그대로 치면 그 자리로 떨어진다. `Ctrl+K`로
어디서든 열리고 `Esc`로 보던 자리로 돌아간다. **검색을 안 쓰는 방문에서는 JS가 실질 0**이다.

그리고 본문을 쓰다 검색 키를 흘리면 **빌드가 멈춘다** — 이 사이트에서 가장 값이 큰 게이트다.

**Blocked by:** 02 — 뼈대 (색인이 `buildDocs()`의 네 번째 산출물로 붙고, 사이드바에 검색창이
앉는다).

**Status:** ready-for-agent

## 토크나이저가 지는 것 셋

의존성은 `minisearch` 하나가 는다. 형태소 경로(`garu-ko` WASM)는 안 간다 — 코퍼스가 조사
코퍼스의 22%(한글 약 7,200자)라 **그 경로의 유일한 근거였던 25 KB 우위가 5 KB로 붕괴한다.**

1. **어절 분해** — 조사는 prefix 확장이 흡수한다 (재현율 60% → 92%)
2. **2-gram** — 복합명사 안쪽을 연다 (→ 100%)
3. **공백 제거 정규화** — 색인을 구울 때 `줄 간격` → `줄간격` 버전도 **함께** 넣는다.
   **2-gram만으로는 띄어쓰기 변형을 못 흡수한다** (어절 경계를 넘는 `줄간`은 색인에 없다)

셋째가 시안에서 실제로 터진 자리다. `줄간격` 질의가 **0건**이었다.

## 화면 — S2 모달

관례를 따랐고 손에 익은 것이 사고 없이 열린다. 대가는 기록해 둔다 — 나비CG와 모니터 한 대를
나눠 쓰는 중이라 **모달이 본문을 덮는다.** 대신 사이드바가 끝까지 발견 전용으로 남아 층위가
화면에서도 안 섞인다.

- 사이드바 검색창은 **정적 HTML**이고, 포커스하거나 `Ctrl+K`를 누르는 **순간에** 색인과 엔진을
  `import()`한다
- 결과 한 줄 = `섹션 › 소제목` + 매치 문맥(하이라이트)
- 포커스 트랩 · 스크롤 잠금 · `aria-modal` · `Esc`로 닫힘
- **초성 검색은 1차 제외.** 순수 추가분이라 나중에 얹어도 문이 안 닫힌다

## 게이트 1 — 질의 20개 재현율 `>= 0.92`

카테고리 결정(1단 트리를 기능 축으로 가른 것)의 **뒤집힐 조건**이 92%다. **테스트가 없으면 그
선을 넘은 것을 아무도 모른다.** 2-gram 실측이 100%이므로 8%p 여유를 두고 지킨다.

**세트에 `줄간격`과 `스타일`을 반드시 넣는다.** 이 둘이 게이트가 잡아야 하는 **두 종류의 대표
표본**이다 — `줄간격`은 **색인 쪽**(공백 제거 정규화가 죽으면 터진다), `스타일`은 **본문
쪽**(`Style Catalog`의 한글 이름을 안 지으면 터진다). 세트는 원본에서 뽑아올 수 없다.
**우리가 지은 한글 이름을 포함해야 한다.**

**본문이 아직 없는 페이지를 겨냥한 질의는 유예한다** — 정답 페이지가 저장소에 생기는 순간
자동으로 게이트에 들어오고, 그때부터 그 질의도 92%를 지켜야 한다. 본문이 늘수록 게이트가
스스로 조여든다.

- [ ] 사이드바 검색창이 정적 HTML이고, 포커스하거나 `Ctrl+K`를 누르는 순간에만 색인·엔진이 내려온다
- [ ] 검색을 안 쓰는 방문에서 본문 페이지의 클라이언트 JS가 여전히 0이다
- [ ] 색인이 빌드에서 구워진다 — 어절 · 2-gram · 공백 제거 정규화 셋이 전부 적용된다
- [ ] `자간`과 `Kerning` 중 무엇을 쳐도 같은 곳이 나온다
- [ ] `줄간격`으로 붙여 쳐도 `줄 간격`이 걸린다
- [ ] `Ctrl+H` 같은 단축키 문자열로도 걸린다
- [ ] 사이드바 한 줄 설명이 색인에 들어간다
- [ ] 결과 한 줄에 `섹션 › 소제목`과 매치 문맥이 뜬다
- [ ] `Esc`로 닫히고 보던 자리로 돌아간다
- [ ] 포커스 트랩 · 스크롤 잠금 · `aria-modal`
- [ ] 질의 20개 세트가 리터럴로 적혀 있고 `줄간격`과 `스타일`이 들어 있다
- [ ] 세트에 우리가 지은 한글 이름이 포함돼 있다
- [ ] **게이트 1** — 재현율이 0.92 아래로 떨어지면 테스트가 실패한다
- [ ] 게이트가 **색인 산출물**에 걸린다 — 토크나이저 내부 자료구조를 보는 테스트가 없다
- [ ] 정답 페이지가 아직 없는 질의는 유예되고, 페이지가 생기면 자동으로 게이트에 들어온다
- [ ] 초성 검색이 없다
