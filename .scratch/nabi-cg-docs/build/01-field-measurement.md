# 01 — 방송실 PC 실측 한 번

**What to build:** 나비CG를 한 번 열어 **세 묶음을 한꺼번에** 받아 적는다. 셋 다 화면 앞에
앉아야만 얻어지는 것이고, 따로 잡으면 방송실에 세 번 간다.

1. **옵션창의 한글 이름** — 우리가 지을 이름 목록이 여기서 확정된다
2. **우리 값 12칸** — 게이트 2·3이 이걸 요구한다
3. **`[화면]` 구멍 10줄 내외** — 매뉴얼이 침묵하는데 화면에 있는 것

이게 늦어지면 본문을 두 번 쓴다. 병기 28종은 **매뉴얼 기준이라 2년 낡은 수치**이고 그 뒤
2025.03에 `옵션창 메뉴 한글화`가 있었다. compix가 이미 지어 둔 한글이 화면에 떠 있다면
**짓는 것보다 화면의 이름을 쓰는 편이 검색 키로 정확하다.**

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

## 산출물은 저장소 밖 노트 하나다

`.scratch/nabi-cg-docs/research/화면-실측.md` 한 장에 셋을 다 적는다. **값을 코드로 옮기는
것은 03이 한다** — 값 파일의 모양과 게이트가 그 티켓의 것이기 때문이다. 여기서는 숫자와
이름을 확보하는 데까지다.

## 받아 적을 것

### 옵션창 한글 이름

1차 7개 섹션에 나오는 용어를 화면에서 훑고 **두 칸으로 가른다** — compix가 이미 지어 둔
한글이냐, 없어서 우리가 지어야 하냐. 뒤 칸이 곧 05의 질의 세트에 들어갈 이름이다.

`Style Catalog` · `Char Unit` · `Take In` 셋은 **매뉴얼에 한글 이름이 없다고 실측된 자리**라
판정을 반드시 표에 남긴다.

### 값 12칸

| 대상 | 값 |
|---|---|
| 설교 자막 | Height · Width · Kerning · Leading |
| 광고 자막 | Height · Width · Kerning · Leading |
| 설교 자막 배경판 | Height · Width |
| 광고 하단바 | Height · Width |

**값마다 출처 파일과 확인일을 단다** — `출처: 2026-08-03 설교자막.카사`. 재확인이 「기억을
뒤지는 일」이 아니라 **「파일 하나 여는 일」**이 되는 것이 이 한 줄의 값이다.

### `[화면]` 구멍

| 자리 | 확인할 것 |
|---|---|
| `§6.1 Playback` | `GA`/`S1`/`S2` 토글, `Stop All` 버튼 (2024.09) |
| `§6.2 Run Setting` | `All File Playback` 모드, `Edit Sync` 옵션, Global Playback 보기 설정 콤보박스 (2024.06·09) |
| `§7 단축키` | `Ctrl+Shift+F5` · `Ctrl+Shift+F9` · `Ctrl+Shift+F8`의 실제 이름과 동작 |

`§6.2`의 모드는 **매뉴얼이 6개, 화면이 7개**로 이미 어긋나 있다. 화면이 이긴다.

- [ ] 1차 7개 섹션 용어의 화면 한글 이름을 표로 적었고, compix가 지은 것과 우리가 지을 것이 갈려 있다
- [ ] `Style Catalog` · `Char Unit` · `Take In` 셋의 판정이 표에 있다
- [ ] 값 12칸이 전부 숫자로 채워졌다
- [ ] 값마다 출처 파일 이름과 확인일이 붙어 있다
- [ ] `§6.1`의 토글·버튼을 화면에서 확인해 적었다
- [ ] `§6.2`의 모드·옵션·콤보박스를 화면에서 확인해 적었다 — 실제 모드 개수를 셌다
- [ ] `Ctrl+Shift+F5`/`F9`/`F8` 세 단축키의 이름과 동작을 적었다
- [ ] **방송실 PC의 나비CG 빌드 날짜를 확인했다** — `2026.02`로 가정하고 있으나 다르면 06의 History 대조와 `NABI_BUILD` 상수가 통째로 달라진다
- [ ] 여기서 확인한 것이 아닌 문장은 이 노트에 없다 — 추측을 적지 않는다
