# 12 — 안내문 4개 + 2차 자리

**What to build:** `교회DB`나 `성경`을 검색하면 **"이 문서에 없습니다"**를 만난다.
*"찾았는데 없다"*가 이 사이트 최악의 실패이고, 잘라낸 34페이지를 우리 문장으로 쓴 안내문 4개가
덮는다. 그리고 2차 67페이지가 **자리와 제목만** 선다.

**Blocked by:** 05 — 검색 (**안내문은 1단 트리에 없고 검색으로만 만난다.** 검색이 서기 전에는
이 페이지들에 도달할 경로가 아예 없다).

**Status:** ready-for-agent

## 안내문 넷

`설치·장비` / `교회DB` / `오디오·영상` / `잘 안 쓰는 도구`. 목차로 남기면 *"344항목 트리를
버리고 새로"* 불변식을 정면으로 어기므로 안내문으로 덮는다.

```markdown
## 이 문서가 다루지 않는 것 — 성경·찬송 자막

성경 구절, 찬송가 가사, 교독문 자막을 **교회 DB 플러그인**으로 만드는 방법은 이 문서에 없습니다.
검색·등록·장절 지정·사용자 관리 전부 해당됩니다.

→ 원본 매뉴얼 `Chapter 3. 교회 DB`
```

- **이유절 없이 사실만.** 이유를 쓰면 운영이 바뀔 때 문장이 거짓말이 된다
- *"없습니다"* / *"아직 없습니다"*가 「영영」과 「지금은」을 가른다
- **대상을 구체적으로 나열해 검색 키를 확보한다** — `교회DB`·`성경`·`찬송`·`설치`·`오디오`가
  본문에 **실제로 박혀 있어야** 검색으로 만난다
- 원본은 **챕터 이름까지만** 가리킨다. 절 번호까지 내려가면 트리 복제에 닿는다
- `설치·장비` 안내문은 `CPX-DL Controller`라는 이름을 담는다 — 2차 이상증상이 그걸 가리킨다

## 2차 자리

67페이지는 **제목만 서고 본문은 비운다.** `Ch1 §4 이상증상 대처법`, `§6.4 Global Animation`,
`§4.3 Custom 도형`이 여기 포함된다. **본문이 비어 `[화면]` 태그가 0개이므로 갱신 대상이
아니다** — 1차/2차 절단의 또 다른 값이다.

- [ ] 안내문 4개가 있고 각각 대상을 구체적으로 나열한다
- [ ] 안내문에 **이유절이 없다**
- [ ] *"없습니다"*와 *"아직 없습니다"*가 구분돼 쓰였다
- [ ] `교회DB`·`성경`·`찬송`·`설치`·`오디오`로 검색하면 해당 안내문이 나온다
- [ ] 안내문이 1단 트리에 **없다** — 사이드바는 여전히 7줄이다
- [ ] 각 안내문이 원본 매뉴얼의 **챕터 이름까지만** 가리킨다 (절 번호 없음)
- [ ] `설치·장비` 안내문에 `CPX-DL Controller`가 들어 있다
- [ ] 2차 자리가 제목만 서고 본문이 비어 있다
- [ ] 2차 페이지에 `[화면]` 태그가 0개다 — 게이트 5의 물량이 안 는다
- [ ] 1단 트리가 여전히 7개다 (**15개 초과가 골격 B의 뒤집힐 조건**이다)
