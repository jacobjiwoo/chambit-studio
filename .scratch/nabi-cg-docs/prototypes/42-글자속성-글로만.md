# 글자 속성 — 크기·간격·굵기 조절

> 프로토타입. `.scratch/nabi-cg-docs/issues/06-screenshots.md`의 "그림 없이 글로만 성립하는가" 시험용.
> 원본 매뉴얼 `Ch2 §4.2 글자 객체 속성 편집`(p.102–108, 6페이지, 그림 23장)을 그림 0장으로 다시 쓴 것.

글자를 선택하면 아래쪽 **Attributes** 탭에 그 글자의 속성이 뜬다. 여기서 크기·간격·굵기를 바꾼다.

---

## 자막이 한 줄에 안 들어갈 때

매주 하는 작업이다. 손대는 순서가 있다 — **위에서부터 시도하고, 안 되면 다음으로 내려간다.**

### 1. Width를 줄인다 (글자를 홀쭉하게)

`Width`는 글자 높이에 대한 **폭의 비율**이다. 100%가 기본이고 10%~800%까지 간다.

높이는 그대로 두고 폭만 좁히는 것이라 **줄이 흐트러지지 않는다.** 그래서 제일 먼저 손대는 값이다.

- 단축키 — 넓히기 `Ctrl+J` / 좁히기 `Ctrl+K`
- 90% 아래로 내려가면 눈에 띄게 답답해 보인다

### 2. Kerning을 좁힌다 (글자 사이를 좁게)

`Kerning`은 **글자와 글자 사이** 간격이다.

- 단축키 — 벌리기 `Ctrl+H` / 모으기 `Ctrl+L`
- 음수까지 내려가면 글자가 서로 붙는다

Width와 Kerning은 성격이 다르다. **Width는 글자 자체를 눌러 찌그러뜨리고, Kerning은 글자 모양은 그대로 두고 사이만 좁힌다.** 한 글자씩 또렷해야 하는 자막에서는 Kerning을 먼저 쓰는 편이 낫다.

### 3. Space를 좁힌다 (띄어쓰기만 좁게)

`Space`는 **띄어쓰기 칸**만 조절한다. 글자 사이는 건드리지 않는다.

띄어쓰기가 많은 문장에서 마지막으로 몇 글자를 벌 수 있는 수단이다.

### 4. Height를 줄인다 (마지막 수단)

`Height`가 글자 크기다. 10~1200까지 지정한다.

- 단축키 — 확대 `Ctrl+I` / 축소 `Ctrl+M`

**여기까지 왔다면 다시 생각해 볼 것** — 한 화면에 넣을 글자가 너무 많은 것일 수 있다. 원고를 두 페이지로 나누는 편이 나은 경우가 많다.

### 여러 줄인데 줄끼리 겹칠 때

`Leading`이 **줄 간격**이다. 한 객체 안에 두 줄 이상 있을 때만 의미가 있다.

Height를 키우면 줄끼리 붙으므로, Height를 건드렸다면 Leading도 같이 봐야 한다.

> **참빛교회 기준값** — 우리가 실제로 쓰는 값을 여기 적는다.
> 설교 자막 / 광고 자막 / 성경 구절별로 Height·Width·Kerning·Leading 기본값.
> *(작성 시 채울 것)*

## 글씨가 잘 안 보일 때

### 굵게 — Bold와 Thickness는 다르다

**`Bold`는 서체에 굵은 버전이 있을 때만 먹는다.** 굵은 버전이 없는 서체에서 Bold를 눌러도 아무 일도 일어나지 않는다.

그럴 때 쓰는 것이 **`Thickness`**다. 서체와 무관하게 획 자체를 두껍게 만든다. 매뉴얼도 *"방송용으로 적합하지 않은 가는 글씨"*에 쓰라고 안내한다.

- 가는 서체를 방송에 써야 한다 → Thickness
- 서체에 Bold가 있다 → Bold 쪽이 모양이 낫다

### 윤곽선만 — Outline

`Outline`은 글자 속을 비우고 **윤곽선만** 남긴다. 혼자 쓰면 선이 너무 가늘어 안 보이므로 **Thickness와 같이 쓴다.**

### 기울임 — Italic

오른쪽으로 살짝 기울인다.

## 나머지 속성

일상 작업에는 거의 안 쓰지만, 있다는 것은 알아둘 것.

| 속성 | 하는 일 | 알아둘 것 |
|---|---|---|
| `Font` | 서체 선택 | 윈도우에 설치된 True Type 폰트는 전부 쓸 수 있다. 목록 맨 아래에 **최근 쓴 폰트 10개**가 따로 모여 있다 |
| `Rotate` | 객체 전체를 회전 | **+가 반시계, −가 시계 방향**이다 (반대로 알기 쉽다) |
| `C-Rotate` | 글자 한 자씩 회전 | 음절 단위. Rotate와 달리 글자마다 돌아간다 |
| `텍스트 정렬` | 객체 안에서 왼쪽/가운데/오른쪽 | 객체의 폭이 기준이다 |
| `Flip Vert / Horz` | 상하·좌우 뒤집기 | 바닥에 비친 반사 효과를 만들 때 쓴다 |
| `Char Unit` | 색을 음절 단위로 넣을지 객체 전체로 넣을지 | Face·Edge·Shadow 색에 적용된다 |
| `Exclude` | **페이지 템플릿 일괄지정에서 이 객체를 뺀다** | 지정하면 레이어에도 표시된다. 템플릿을 일괄 적용하는데 이 객체만 안 바뀐다면 여길 확인 |

## Text Link — 텍스트 파일을 물려두는 기능

글자 객체 하나에 `.txt` 파일 하나를 연결한다. **파일 내용이 바뀌면 다음 송출 때 자동으로 갱신되어 나간다.**

- 객체를 고르고 `Text Link` 버튼 → 파일 선택
- 이미 연결돼 있으면 같은 버튼이 **그 파일이 있는 폴더를 연다**

**연결한 뒤에는 작업창에서 글자 내용을 못 고친다.** 크기·색·서체는 그대로 바꿀 수 있다.

**주의할 것 세 가지**

1. **줄바꿈을 txt에서 미리 해둬야 한다.** 내용이 그대로 표시되므로, 길고 줄바꿈이 없으면 화면 밖으로 넘어간다.
2. **연결된 txt는 자막 파일에 같이 저장되지 않는다.** 다른 PC로 옮길 때는 txt를 같은 경로에 따로 옮겨야 한다.
3. **파일을 못 찾으면 마지막으로 읽은 내용이 그대로 나간다.** 이때 파일명에 취소선이 그어지므로, 취소선이 보이면 실제 내용과 다를 수 있다고 의심할 것.
