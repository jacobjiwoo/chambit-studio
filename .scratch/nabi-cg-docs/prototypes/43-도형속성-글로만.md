>
> **조사 정정** — `research/manual-toc.md`는 이 절을 p.108–110으로 적었으나 실제로는 **p.109–111**이다. p.108은 §4.2의 Text Link 꼬리다.

도형을 선택하면 아래쪽 **Attributes** 탭에 그 도형의 속성이 뜬다. 자막 글자 뒤에 까는 반투명 판이 대부분 여기서 조절된다.

---

## 자막이 길어져 배경 도형을 늘려야 할 때

매주 하는 작업이다. **글자 폭을 줄이는 것과 도형을 늘리는 것 중 어느 쪽을 먼저 할지**가 실질적인 판단이고, 순서는 이렇다.

1. **도형을 먼저 늘린다.** 화면에 여유가 있으면 도형 `Width`를 키우는 쪽이 글자를 건드리는 것보다 항상 낫다 — 글자는 손대는 순간 읽기가 나빠진다.
2. **화면 폭이 다 찼으면** 그때 글자 쪽으로 간다 → `글자 속성`

`Height`·`Width`가 도형의 높이와 너비다. 마우스로 끄는 것보다 숫자로 넣는 편이 여러 페이지에서 같은 크기를 맞추기 쉽다.

> **참빛교회 기준값** — 설교 자막 배경판 / 광고 하단바의 Height·Width.
> *(작성 시 채울 것)*

---

## 도형 종류 여덟 가지

도형 모드 버튼을 누르고 편집창을 드래그하면 도형이 생긴다. 종류는 `Shape Type`에서 고른다.

**`Framed`가 붙은 것은 속이 빈 테두리 도형이다.** 이 규칙만 알면 목록이 절반으로 줄어든다.

| Shape Type | 모양 |
|---|---|
| `Box` | 사각형, 속 채움 |
| `Framed Box` | 사각형 테두리만 |
| `Circle` | 원(타원), 속 채움 |
| `Framed Circle` | 원 테두리만 |
| `Diamond` | 마름모, 속 채움 |
| `Framed Diamond` | 마름모 테두리만 |
| `Rounded Rectangle` | 모서리가 둥근 사각형 |
| `Octagon` | 팔각형 — 사각형의 네 모서리를 잘라낸 모양 |
| `Custom` | 직접 그리는 자유 도형 |

**자막 배경으로는 `Box`와 `Rounded Rectangle`이면 거의 다 된다.**

### 테두리 도형의 선 굵기 — Pen Size

`Framed`가 붙은 도형에서만 활성화된다. 선이 얼마나 굵은지를 정한다.

### 모서리 깎기 — Arc Height / Arc Width

**`Rounded Rectangle`과 `Octagon`에서만 활성화된다.** 모서리를 얼마나 둥글게(또는 비스듬하게) 깎을지를 정한다.

높이·너비를 따로 주므로 모서리를 타원형으로 깎을 수도 있다. 값을 0으로 하면 그냥 `Box`와 같아진다.

### 회전 — Rotate

도형을 돌린다. 글자와 같은 규칙이다 — **`+`가 반시계, `−`가 시계 방향**.

## Custom 도형 — 곡선을 직접 그리기

`Custom`을 고르고 그리면 조절점이 생긴다. 두 종류다.

- **빨간 점 = 프레임 포인트** — 도형의 꼭짓점. 처음 그리면 3개 생긴다.
- **녹색·파란 점 = 컨트롤 포인트** — 프레임 포인트마다 양옆에 하나씩. 이걸 움직여 그 구간의 **곡선이 휘는 정도**를 바꾼다.

**꼭짓점 추가/삭제** — 컨트롤 포인트에서 오른쪽 클릭 → `프레임을 추가`. 지울 때는 지울 프레임 포인트를 고르고 오른쪽 클릭.

**링크** — 프레임 포인트 하나와 양옆 컨트롤 포인트 둘, 이렇게 셋을 한 덩어리로 묶는 기능이다. 묶어두면 셋이 같이 움직여서 **꺾이지 않고 매끄럽게 이어지는 곡선**이 나온다. 링크를 풀면 좌우를 따로 움직일 수 있어 뾰족한 꼭짓점을 만들 수 있다.

> ⚠ **이 절은 글로 옮기기 가장 어려운 자리다.** 곡선 조절은 손으로 끌어보면서 익히는 것이라, 문장으로 읽어서는 감이 오지 않는다.
> 다만 **자막 배경판을 만드는 데 Custom 도형이 필요한 경우는 사실상 없다** — 티켓 05가 이 절을 1차로 올린 이유는 "자막이 길어져 도형 크기 조절"이었고 그건 위쪽 `Height`/`Width` 얘기다.
> **2차로 내리거나, 범위 밖으로 빼도 되는지 확인이 필요하다.**

## 관련

- 글자 크기·간격 → `글자 속성`
- 도형 색·투명도·그라데이션 → `Color`
- 테두리·그림자 → `객체 스타일`
- 여러 도형을 한꺼번에 같은 크기로 → `객체 편집`의 크기 맞추기
