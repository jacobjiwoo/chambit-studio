# 10: PPT 만들기

Status: resolved
Blocked by: 03

## 무엇을 만드나

담당자가 버튼 하나로 **셋리스트** 전체를 16:9 `.pptx` 한 벌로 만들어 `찬양_YYYYMMDD.pptx`로 받는다. spec 유저 스토리 53–65, 69.

세부는 [spec](../spec.md)의 "`.pptx` 쓰기"와 "화면"의 상단·만들기 창 항목에 있다.

- 만들기 버튼: "PPT 만들기 · N곡", 셋리스트가 비면 비활성.
- `.pptx` 쓰기: [03](03-foundation.md)의 생성 계획을 받아 Blob을 돌려주는 얇은 모듈이다. pptxgenjs는 버튼을 누를 때 dynamic import한다. 레이아웃 10 × 5.625 inch, 장마다 배경(색 또는 이미지) + 슬라이드 이미지를 (0, 0)부터 가득. 곡 목록 곡의 이미지는 `fetch`해 base64로, 올린 곡은 이미 data URL이다. 이미지 하나라도 못 받으면 전체 실패다. seam 밖이라 테스트를 요구하지 않는다.
- 만들기 창: 진행 중(닫기 버튼 없음, Esc·바깥 클릭 막음), 성공(파일 이름·곡 수·슬라이드 수·크기 MB 소수 둘째 자리, "새로 만들기"는 창만 닫음, "다운로드"), 실패(오류 메시지, "닫기", "다시 시도"). 성공·실패 창은 Esc·바깥 클릭·닫기로 닫힌다. 가짜 단계 타이머와 confetti는 옮기지 않는다.
- 다운로드는 Blob의 object URL을 가진 링크를 눌러 받고, 받은 뒤 URL을 해제한다.
- 생성 계획의 실패 사유("곡이 선택되지 않았습니다", "생성할 슬라이드가 없습니다")는 실패 창에 그대로 보인다.

**맡는 범위:** 03이 만든 만들기 버튼·만들기 창 컴포넌트와 그 아래, `.pptx` 쓰기 모듈. 루트와 다른 구역은 고치지 않는다. props가 모자라면 고치지 말고 `## Comments`에 적는다.

R2 CORS([02](02-r2-domain-cors.md))가 붙기 전에는 곡 목록 곡으로 만들기가 실패한다. 이 티켓은 **올린 곡**으로 끝까지 확인하고, 곡 목록 곡은 [11](11-end-to-end-check.md)에서 확인한다.
