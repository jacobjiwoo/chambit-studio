# 07: 셋리스트 순서 목록과 드래그 정렬

Status: resolved
Blocked by: 03

## 무엇을 만드나

담당자가 **셋리스트**를 순번·제목·사용 장수로 훑고, 끌거나 키보드로 순서를 바꾸고, 곡을 뺀다. spec 유저 스토리 14–17, 19(이 구역의 빈 상태).

세부는 [spec](../spec.md)의 "화면"에서 원본의 "담은 곡" 구역 항목에 있다.

- 목록: 곡 수, 곡마다 순번·제목·"N장 사용"·빼기 버튼, 빈 상태 안내.
- 드래그 정렬은 dnd-kit이다: 포인터 센서(4px 움직여야 시작) + 키보드 센서, 세로축·부모 안으로 제한, 놓은 자리의 곡 위치로 순서 바꾸기. 순서 바꾸기 자체는 [03](03-foundation.md)의 셋리스트 조작을 쓴다.
- 스타일 없이 의미 있는 HTML로 쓴다. 드래그 중 위치가 보일 만큼의 transform만 dnd-kit 기본대로 건다.

**맡는 범위:** 03이 만든 셋리스트 순서 목록 구역 컴포넌트와 그 아래. 루트와 다른 구역은 고치지 않는다. props가 모자라면 고치지 말고 `## Comments`에 적는다.

확인할 때는 셋리스트에 곡이 있어야 한다. 05·06이 아직이면 localStorage에 셋리스트 값을 직접 넣거나 임시 곡 목록 JSON을 쓰되 커밋하지 않는다.

## 완료 조건

- [x] 셋리스트의 곡마다 순번·제목·사용 장수(전체에서 뺀 장을 제외한 수)가 보인다
- [x] 마우스로 끌어 순서를 바꿀 수 있고, 4px 안의 클릭은 드래그로 시작되지 않는다
- [x] 키보드(포커스 → 스페이스 → 화살표 → 스페이스)로 순서를 바꿀 수 있다
- [x] 빼기 버튼으로 곡 하나를 뺄 수 있다
- [x] 바꾼 순서가 새로고침 뒤에도 남는다
- [x] 셋리스트가 비면 안내가 보인다
- [x] `pnpm build`, `pnpm lint`, `pnpm typecheck`가 통과한다
