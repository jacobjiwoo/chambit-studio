# 09: 배경 — 공통 배경 막대와 배경 서랍

Status: resolved
Blocked by: 03

## 무엇을 만드나

담당자가 모든 슬라이드에 깔릴 공통 배경과 곡 하나에만 쓸 곡별 배경을 색 프리셋이나 이미지로 정하고, 곡별 배경을 지워 공통 배경으로 되돌린다. spec 유저 스토리 43–47, 49–52.

세부는 [spec](../spec.md)의 "데이터 모델"(배경, 프리셋)과 "화면"에서 셋리스트 상세의 공통 배경 막대, 배경 서랍 항목에 있다.

- 공통 배경 막대: 현재 배경 이름과 미리보기, "배경 바꾸기"(공통 범위로 서랍을 연다).
- 배경 서랍은 공통 범위와 곡 범위 두 가지로 열린다.
  - 부제: 공통이면 "전체 슬라이드에 적용됩니다", 곡이면 곡별 배경 유무에 따라 "이 곡에만 적용됩니다" / "현재 글로벌 배경 사용 중 — 색을 선택하면 이 곡에만 적용됩니다".
  - 색 프리셋 8개를 누르면 그 범위의 배경이 바로 바뀐다. 이미지 파일(`accept="image/*"`)을 고르면 data URL로 읽어 바로 바꾼다. 읽기에 실패하면 아무것도 바꾸지 않는다.
  - 선택 표시와 "현재 업로드 이미지" 미리보기는 공통 범위이거나 곡별 배경이 있을 때만 보인다.
  - 하단: "선택: 이름" 또는 "적용된 곡별 배경 없음", 곡 범위이고 곡별 배경이 있을 때 "글로벌로 되돌리기", 완료. Esc·바깥 클릭으로 닫힌다.
- 프리셋, 배경 이름, 곡별 배경 정하기·지우기는 [03](03-foundation.md)의 `_lib`과 셋리스트 조작을 쓴다.
- 스타일은 색 견본과 미리보기가 보일 만큼만 둔다.

**맡는 범위:** 03이 만든 공통 배경 막대·배경 서랍 컴포넌트와 그 아래. 곡 카드의 곡별 배경 버튼은 [08](08-setlist-detail-slide-editor.md)의 것이다. 루트와 다른 구역은 고치지 않는다. props가 모자라면 고치지 말고 `## Comments`에 적는다.

## 완료 조건

- [x] 공통 배경 막대에 현재 배경 이름(프리셋 이름 / `#RRGGBB` / "업로드 이미지")과 미리보기가 보인다
- [x] 공통 범위에서 프리셋이나 이미지를 고르면 공통 배경이 바로 바뀐다
- [x] 곡 범위에서 고르면 그 곡의 곡별 배경만 바뀌고, 곡별 배경이 없는 곡은 공통 배경을 따른다
- [x] 곡별 배경이 없을 때 곡 범위 서랍에는 선택 표시가 없고, "글로벌로 되돌리기"로 곡별 배경이 지워진다
- [x] 곡별 배경은 새로고침 뒤에도 남고, 공통 배경은 흰색으로 돌아간다
- [x] 서랍이 Esc, 바깥 클릭, 완료로 닫힌다
- [x] `pnpm build`, `pnpm lint`, `pnpm typecheck`가 통과한다

- `background-drawer.tsx`: 부제, 프리셋 8개, 이미지 고르기(`FileReader`로 data URL, 실패하면 아무것도 바꾸지 않는다), 선택 표시와 "현재 업로드 이미지"는 공통 범위이거나 곡별 배경이 있을 때만, 하단 문구·"글로벌로 되돌리기"·완료, Esc·바깥 클릭으로 닫기. 같은 파일을 다시 골라도 바뀌도록 고른 뒤 input을 비운다.
