# 08: 셋리스트 상세와 슬라이드 편집 서랍

Status: ready-for-agent
Blocked by: 03

## 무엇을 만드나

담당자가 **셋리스트**의 곡마다 슬라이드 썸네일을 적용될 배경 위에서 훑고, 슬라이드 편집 서랍에서 장마다 넣을지 뺄지 정한다. spec 유저 스토리 18, 19, 34–42, 48(곡 카드의 곡별 배경 표시).

세부는 [spec](../spec.md)의 "화면"에서 셋리스트 상세, 곡 카드, 슬라이드 편집 서랍 항목에 있다.

- 셋리스트 상세: 제목과 곡 수, "총 N장의 슬라이드가 PPT로 만들어집니다"(N은 [03](03-foundation.md)의 생성 계획 길이) 또는 비었을 때 안내, "전체 비우기", 곡 카드 목록, 비었을 때 3단계 시작 안내(검색 → 담기 → PPT 만들기).
- 곡 카드: 순번, 제목, "N장 사용 · M장 제외(또는 전체) · T장 중", 곡별 배경 버튼(곡별 배경이 있으면 표시와 그 이름), "슬라이드 편집" 버튼, 썸네일 줄(적용 배경 위에 이미지, 번호, 뺀 장은 흐리게, `loading="lazy"`). 썸네일 밖의 카드를 누르면 슬라이드 편집이 열린다.
- 슬라이드 편집 서랍: 곡 제목, "사용할 슬라이드를 골라주세요 · 전체 N장", 전체 포함·전체 제외, 썸네일 격자(누르면 제외 토글, 포함/제외 표시), "U / T장 사용", 완료. Esc·바깥 클릭으로 닫힌다. `<dialog>`처럼 의미 있는 요소를 쓴다.
- 곡별 배경 버튼은 03의 서랍 열기 콜백만 부른다. 배경 서랍 자체는 [09](09-background.md)가 만든다.
- 스타일은 "뺀 장을 흐리게"와 "배경 위에 이미지"를 보이게 하는 최소한만 둔다.

**맡는 범위:** 03이 만든 셋리스트 상세·곡 카드·슬라이드 편집 서랍 컴포넌트와 그 아래. 공통 배경 막대(09), 루트, 다른 구역은 고치지 않는다. props가 모자라면 고치지 말고 `## Comments`에 적는다.

썸네일은 R2 커스텀 도메인([02](02-r2-domain-cors.md))이 붙기 전에는 곡 목록 곡에서 깨진다. 그동안은 올린 곡이나 깨진 이미지 자리로 확인한다.

## 완료 조건

- [ ] 곡 카드마다 사용·제외·전체 장수와 썸네일 줄이 보이고, 뺀 장이 흐리다
- [ ] 썸네일이 그 곡에 적용되는 배경(곡별 배경, 없으면 공통 배경) 위에 보인다
- [ ] 슬라이드 편집 서랍에서 장마다 제외를 토글하고, 전체 포함·전체 제외를 할 수 있다
- [ ] 서랍이 Esc, 바깥 클릭, 완료로 닫힌다
- [ ] "총 N장"이 셋리스트 전체의 사용 장수 합과 같다
- [ ] "전체 비우기"로 셋리스트가 빈다. 비었을 때 3단계 안내가 보인다
- [ ] 제외 상태가 새로고침 뒤에도 남는다
- [ ] `pnpm build`, `pnpm lint`, `pnpm typecheck`가 통과한다
