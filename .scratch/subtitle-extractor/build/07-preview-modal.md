# 07 — 미리보기 모달

**What to build:** 받기 전에 **파일에 들어갈 원문 그대로**를 띄운다. 자막 목록은 장 단위로 끊어
보여줄 뿐 나비CG가 실제로 읽을 모습과 생김새가 다르므로, 마지막 확인은 원문으로 한다.

**Blocked by:** 04 — 올린다 → 받는다.

**Status:** ready-for-agent

## 세부

미리보기 버튼은 받기 버튼 **옆**에 있다. 모달 본문은 자막 장이 **빈 줄로 갈리는 것을 눈으로
볼 수 있어야** 한다 — 나비CG의 페이지 구분이 제대로 될지 미리 아는 통로다.

푸터에 `UTF-8 BOM · CRLF · 자막 N장 · 장 구분은 빈 줄`. 손으로 맞추던 형식이 제대로 들어갔는지
여기서 확인한다.

**모달 안에서 바로 받을 수 있다.** 확인한 뒤 모달을 닫고 버튼을 다시 찾는 걸음이 생기면 안 된다.

모달 열림 상태는 그것이 쓰이는 컴포넌트 안에 산다.

- [ ] 미리보기 버튼이 받기 버튼 옆에 있다
- [ ] 모달이 파일에 들어갈 원문 그대로를 보여준다 (장 단위로 끊은 목록이 아니다)
- [ ] 자막 장 사이의 빈 줄이 눈에 보인다
- [ ] 푸터에 인코딩 · 개행 · 자막 장 수 · 장 구분 방식이 쓰여 있다
- [ ] 모달 안의 받기 버튼이 헤더의 받기와 완전히 같은 파일을 떨군다
- [ ] 자막이 긴 원고(19장)에서도 모달 안이 스크롤되고 화면을 넘치지 않는다
