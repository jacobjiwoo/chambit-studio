# 09: 장비 그림의 그리는 순서를 저장해 둔다

Type: task
Status: resolved
Blocked by: 06

## 무엇을 하나

장비 그림은 모듈을 불러올 때마다 부품의 앞뒤 순서를 잰다(`A.settle`). 세 장비 여섯 시점에 20초쯤 걸려 `pnpm test`가 27초, 개발 서버의 장비 목록표·신호 흐름도 첫 로딩이 13–24초가 됐다. 잰 순서를 파일로 저장해 그림이 그대로면 다시 재지 않게 한다.

## 끝난 조건

- 저장된 순서로 그린 SVG가 다시 잰 것과 글자 하나까지 같다.
- 그림이 바뀌면 저장된 순서를 쓰지 않고, 테스트가 저장 파일을 고치라고 알린다.

## Answer

- **저장.** `_lib/device-figure-order.json`에 시점마다 지문(`hash`)과 그리는 순서(`order`)를 둔다. 지문은 부품의 이름과 SVG로 만든 해시라, 좌표 하나만 바뀌어도 달라진다. 지문이 맞으면 `scene.finish`가 `A.settle`을 건너뛴다.
- **낡았을 때.** 지문이 다르면 그 자리에서 다시 잰다. 그림은 맞게 나오고 느려질 뿐이다. `device-figures.test.ts`의 "저장해 둔 그리는 순서가 그림과 맞는다"가 낡은 시점 이름을 보이며 멈춘다. `UPDATE_FIGURE_ORDER=1 pnpm test`로 파일을 고친다.
- **audit.** 저장된 순서를 쓴 그림은 순서를 재지 않은 채라, audit 테스트가 `settleView`로 먼저 잰다.
- **결과.** 여섯 시점의 SVG가 고치기 전과 md5까지 같다. `pnpm test`는 27초 → 2.9초, 개발 서버의 신호 흐름도 페이지는 13–24초 → 0.6초다.
- **확인 못 한 것.** 지문은 부동소수 계산 결과에 달려 있다. macOS에서 만든 지문이 CI(Linux)에서도 같은지는 CI 결과로 본다. 다르면 위 테스트가 CI에서 멈춘다.
