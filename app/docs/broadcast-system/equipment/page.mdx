## CG 출력 원리 (하드웨어)

- CG PC의 NABI-CG가 CG를 만들면, PC 안의 문자발생기 보드가 이를 방송 신호 2개로 내보낸다.
  - FILL: CG의 색과 모양 (CG_FILL로 멀티뷰에 보이는 화면)
  - KEY: CG가 있는 곳은 흰색, 없는 곳은 검은색인 "오려낼 모양" 신호
- 영상 스위처는 DSK(Downstream Keyer, 최종 단계에서 CG를 얹는 기능)로 KEY 모양대로 PGM을 오려내고 그 자리에 FILL을 채워 넣는다. DSK ON/OFF로 CG 켜기/끄기를 한다.
- DSK는 PGM 맨 마지막 단계에서 얹히므로, 카메라를 전환해도 CG는 유지되고 PGM을 받는 모든 곳(LED 스크린·온라인 송출 등)에 함께 나간다.
- 출력 포맷은 다른 장비와 동일하게 HD 1080i 59.94여야 한다(NABI 매뉴얼 권장값, 백업 녹화기 표시값과 일치, 문자발생기 보드 설정값 확인 완료).

## 온라인 송출 신호 흐름 (선임 설명 반영, 2026-11-01)

장비 4대가 SDI 케이블로 한 줄로 이어진 <Unconfirmed>직렬 구조</Unconfirmed>(선임 설명).

1. <Unconfirmed>영상 스위처 → 영상 hub</Unconfirmed> (SDI, PGM+CG)
2. 영상 hub → 오디오 임베더 SDI IN (SDI)
3. 음향 콘솔 → (<Unconfirmed>오디오 분배기 출력1 "스트리밍" 경유 여부</Unconfirmed>) → 오디오 임베더 CH1·CH2 (XLR ×2)
4. 오디오 임베더 → 백업 송출 장비 SDI IN (SDI, 영상+소리) ← 화면과 소리가 처음 합쳐진 뒤
5. 백업 송출 장비 SDI OUT → 백업 녹화기 SDI IN (SDI)
6. 백업 녹화기 SDI OUT → 송출 PC 캡처카드 (SDI)
7. 송출 PC OBS → 유튜브 (RTMP)

- 이 구조를 택한 이유(선임 설명)와 확인할 거리:
  - 선임 설명: "오디오 임베더 → 송출 PC로 긴 SDI 선을 사기에 비쌌다". 확인할 거리: 일반 HD-SDI 케이블은 10m급도 수만 원대이고, 같은 영상 데스크 안이라 거리도 길지 않을 것으로 보인다. <Unconfirmed>당시 다른 사정이 있었는지</Unconfirmed>.
  - 선임 설명: "OBS 도입 당시, 문제가 생겨도 기존 백업 녹화·송출로 넘어갈 수 있게". 직렬 구조에서는 송출 PC가 고장 나도 백업 장비는 신호를 계속 받는다. 반대로 백업 장비가 고장 나면 주 송출도 끊긴다. OBS 도입 전 주 장비였던 줄 끝에 송출 PC를 덧붙인 구조로 추정.
- 개선 제안은 [업그레이드 제안](https://github.com/jacobjiwoo/chambit-studio/blob/main/.scratch/broadcast-system/upgrade-proposals.md) 1번 참고. 사이트에 올리지 않는 작업 문서라 GitHub 저장소에서 열린다.

## 현황 메모

- 전원 켜는 순서(배운 대로): ① 전압조정기 POWER 차단기 → ② 전압조정기 OUT ON → ③ 음향 UPS → 영상 전원 시퀀서 (<Unconfirmed>시퀀서 순서 위치</Unconfirmed>). 끄는 순서는 역순이 원칙이나 <Unconfirmed>실제 운영 방식</Unconfirmed>.
- 방송실 PC는 2대. 영상 데스크 위 화면을 왼쪽부터: 송출 PC 모니터(작은 LG) → CG PC 모니터(가운데 LG) → 멀티뷰 (사용자 확인).
- 영상 데스크 뒷면은 케이블이 정리·라벨링되지 않은 상태라 사진으로 연결 추적이 불가능함 (2026-10-26). 뒷면 기반 확인은 보류.
- 안전: 영상 데스크 뒷면에 멀티탭 여러 개가 케이블 더미 속에 묻혀 있고, 꽂히지 않은 변환 플러그가 매달려 있음. 케이블을 당기거나 정리할 때는 장비 전원을 끈 뒤 담당자와 함께 진행. 오디오 임베더도 이 케이블 더미 속에 있으므로 건드릴 때 특히 주의(전원 어댑터가 빠지면 온라인 송출이 끊김).

## 확인 필요 목록 (우선순위)

1. 평소 녹화 방식 — 홈페이지에 올리는 녹화본이 OBS 녹화 파일인지, 백업 녹화기 SD카드 파일인지
2. 영상 hub 사진 — 제조사·모델·포트 라벨·연결 상태. 선임 설명(출력 2개 = 오디오 임베더·멀티뷰)과 멀티뷰 분할 화면 구조가 어떻게 이어지는지
3. 직렬 구조 실물 확인 — 오디오 임베더 → 백업 송출 장비 → 백업 녹화기 → 송출 PC 캡처카드 (백업 녹화기 앞 화면의 입력·오디오 레벨, 백업 송출 장비 웹 화면, 케이블 추적)
4. 백업 녹화기 동작 — 평소 녹화 상태로 두는지, 재생 상태가 되면 송출 PC로 재생 영상이 나가는지
5. 오디오 임베더 XLR 2개의 출발 장비 — 음향 콘솔 직결인지, 오디오 분배기 출력1 "스트리밍" 경유인지
6. 영상 스위처 출력 설정 — 스위처 메뉴의 출력 할당 화면으로 확인 (영상 hub로 가는 SDI OUT 번호, 멀티뷰 출력 포함)
7. 백업 송출 장비 HDMI IN 출발 장비, 입력 선택(SDI/HDMI)과 SDI OUT의 관계
8. HDMI 입력 출발 장비 — LED 프로세서 HDMI1, TV 채널 변환기 (영상 스위처는 HDMI 출력이 없어 중간 변환기 가능성)
9. OBS 비디오 설정(FPS, 해상도)과 소스 디인터레이스 설정, 프로필 이름 "백업"의 의미
10. 오디오 분배기 출력2 "RF-" 용도
11. 전원 계통: 전압조정기가 어디까지 공급하는지, 영상 전원 시퀀서를 켜는 순서와 채널별 연결 장비, 음향 앰프 전원 위치, 오디오 임베더 전원 어댑터가 꽂힌 곳
12. 무선 마이크 수신기 5\~6 사용 여부
13. 스위처 버튼 "CP"의 뜻, CAM5·CAM6 위치
14. (보류) 영상 스위처 · 백업 녹화기 · LED 프로세서 · TV 채널 변환기 뒷면 연결
15. (보류) PTZ 컨트롤러 정확한 모델명
