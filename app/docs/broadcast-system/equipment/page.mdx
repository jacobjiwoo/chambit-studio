## CG 출력 원리 (하드웨어)

import { CgOutputFigure } from "../_components/cg-output-figure";

<CgOutputFigure />

- CG PC의 NABI-CG가 CG를 만들면, PC 안의 문자발생기 보드가 이를 방송 신호 2개로 내보낸다.
  - FILL: CG의 색과 모양 (CG_FILL로 멀티뷰에 보이는 화면)
  - KEY: CG가 있는 곳은 흰색, 없는 곳은 검은색인 "오려낼 모양" 신호
- 영상 스위처는 DSK(Downstream Keyer, 최종 단계에서 CG를 얹는 기능)로 KEY 모양대로 PGM을 오려내고 그 자리에 FILL을 채워 넣는다. DSK ON/OFF로 CG 켜기/끄기를 한다.
- DSK는 PGM 맨 마지막 단계에서 얹히므로, 카메라를 전환해도 CG는 유지되고 PGM을 받는 모든 곳(LED 스크린·온라인 송출 등)에 함께 나간다.
- 출력 포맷은 다른 장비와 동일하게 HD 1080i 59.94여야 한다(NABI 매뉴얼 권장값, 백업 녹화기 표시값과 일치, 문자발생기 보드 설정값 확인 완료).

## 온라인 송출 신호 흐름

온라인 송출 직렬 구조와 장비 사이의 연결 그림은 [신호 흐름도](/docs/broadcast-system/signal-flow)에 있다.

## 현황 메모

- 전원 켜는 순서(배운 대로): ① 전압조정기 POWER 차단기 → ② 전압조정기 OUT ON → ③ 음향 UPS → 영상 전원 시퀀서 (<Unconfirmed>시퀀서 순서 위치</Unconfirmed>). 끄는 순서는 역순이 원칙이나 <Unconfirmed>실제 운영 방식</Unconfirmed>.
- 방송실 PC는 2대. 영상 데스크 위 화면을 왼쪽부터: 송출 PC 모니터(작은 LG) → CG PC 모니터(가운데 LG) → 멀티뷰 (사용자 확인).
- 영상 데스크 뒷면은 케이블이 정리·라벨링되지 않은 상태라 사진으로 연결 추적이 불가능함 (2026-10-26). 뒷면 기반 확인은 보류.
- 안전: 영상 데스크 뒷면에 멀티탭 여러 개가 케이블 더미 속에 묻혀 있고, 꽂히지 않은 변환 플러그가 매달려 있음. 케이블을 당기거나 정리할 때는 장비 전원을 끈 뒤 담당자와 함께 진행. 오디오 임베더도 이 케이블 더미 속에 있으므로 건드릴 때 특히 주의(전원 어댑터가 빠지면 온라인 송출이 끊김).
