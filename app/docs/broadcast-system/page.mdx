# 방송 시스템

참빛교회 방송실의 장비, 연결, 운영을 정리한 문서입니다. 방송부원과 교회 사역자가 읽습니다. 다 알아낸 뒤에 쓰는 문서가 아니라 알아가는 대로 고쳐 나가는 문서라서, 아직 비어 있거나 틀릴 수 있는 곳이 있습니다.

## 미확인 배지

사진이나 설명만으로는 확실하지 않은 내용은 <Unconfirmed>이렇게</Unconfirmed> 표시합니다. 내용이 없이 <Unconfirmed />만 있으면 이 줄 전체가 아직 확인되지 않았다는 뜻입니다. 배지가 붙은 내용은 직접 확인하기 전까지 사실로 믿지 마세요.
