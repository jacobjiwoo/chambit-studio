도형을 선택하면 아래쪽 **Attributes** 탭에 그 도형의 속성이 뜬다.[원본 p.80] 자막 글자 뒤에 까는 반투명 배경판과 광고 하단바가 둘 다 여기서 조절된다.[운영]

새 도형은 편집창에서 마우스를 끌어 그린다.[원본 p.80] 그리기 전에 `R`을 눌러 **도형 입력모드**로 바꾸고, 다 그렸으면 `Esc`로 객체 선택 모드로 돌아온다.[원본 p.108]

## 자막이 길어져 배경판을 늘려야 할 때

매주 하는 작업이다.[운영] **글자를 줄이는 것과 배경판을 늘리는 것 중 어느 쪽을 먼저 하느냐**가
실질적인 판단이고, 순서가 있다.[운영]

### 1. 배경판을 먼저 늘린다 — Height(높이) / Width(너비)

`Height(높이)`와 `Width(너비)`가 도형의 높이와 너비다.[원본 p.82] 화면에 여유가 있으면 배경판을
늘리는 쪽이 항상 낫다 — 글자는 손대는 순간 읽기가 나빠진다.[운영]

- 마우스로 끄는 것보다 **숫자로 넣는다** — 여러 페이지에서 같은 크기를 맞춰야 하기 때문이다[운영]
- 도형에는 글자 같은 크기 조절 단축키가 없다. `Attributes` 탭의 숫자 칸이 유일한 길이다[추론]

### 2. 화면 폭이 다 찼으면 글자를 줄인다

배경판을 더 못 늘리는 자리에서 [글자 속성](/docs/nabi-cg/text-attributes)으로 넘어간다.[운영]
무엇부터 손대는지는 그 페이지에 번호로 적어 뒀다.[운영]

### 여러 도형의 크기를 한꺼번에 맞추기

한 페이지에서 맞춘 크기를 다른 페이지로 옮길 때는 숫자를 받아 적지 않는다.[운영] 객체를 고르고
`Ctrl+B`(객체속성일괄지정)를 누르면 여러 객체의 속성을 한 번에 지정한다.[원본 p.108]

## 어떤 도형을 쓸까 — Shape Type(도형 종류)

**이름에 `Framed`가 붙은 것은 속이 빈 테두리 도형이다.**[추론] 매뉴얼이 규칙으로 적어 둔 것은
아니고, p.80에 나란히 실린 여덟 장을 놓고 읽은 것이다.[추론] 이 규칙 하나면 목록이 절반으로
줄어든다.[추론]

| Shape Type | 모양 |
|---|---|
| `Box` | 사각형, 속 채움[원본 p.80] |
| `Framed Box` | 사각형, 테두리만[원본 p.80] |
| `Circle` | 원(타원), 속 채움[원본 p.80] |
| `Framed Circle` | 원, 테두리만[원본 p.80] |
| `Diamond` | 마름모, 속 채움[원본 p.80] |
| `Framed Diamond` | 마름모, 테두리만[원본 p.80] |
| `Rounded Rectangle` | 모서리가 둥근 사각형[원본 p.80] |
| `Octagon` | 팔각형 — 사각형의 네 모서리를 잘라낸 모양[원본 p.80] |

**자막 배경판과 하단바는 `Box`와 `Rounded Rectangle` 둘이면 거의 다 된다.**[운영]

### 모서리를 깎는다 — Arc Height / Arc Width

`Rounded Rectangle`과 `Octagon`에서만 쓴다.[원본 p.82] 모서리를 얼마나 깎을지를 정한다.[원본 p.82]

높이와 너비를 따로 주므로 모서리를 타원형으로 깎을 수도 있다.[추론] 값을 0으로 하면 `Box`와
같아진다.[추론]

### 테두리 도형의 선 두께 — Pen Size(선 굵기)

`Framed`가 붙은 도형에서 선의 두께를 정한다.[원본 p.82] 속을 채운 도형에서는 쓸 일이 없다.[추론]

## 배경판을 반투명하게 — 색과 Alpha(투명도)

도형 색은 `Color`에서 정한다 — 단색·그러데이션·텍스쳐 매핑 중에 고른다.[원본 p.89] 자막 배경판은
대개 단색(`Solid`) 하나로 끝난다.[운영]

**투명도는 색과 따로 논다.**[추론] `Alpha(투명도)`는 컬러팔레트와 상관없이 **숫자로** 조정한다 —
`A` 버튼을 누른 상태에서 값을 넣고, **0이 완전 투명이고 255가 불투명이다.**[원본 p.92]

- 배경판이 글자를 잡아먹으면 Alpha를 먼저 내려 본다 — 크기를 줄이는 것보다 되돌리기 쉽다[운영]
- 화면에 이미 있는 색을 그대로 쓰려면 스포이트를 쓴다. 작업창 밖의 색도 집힌다[원본 p.92]

## 나머지 속성

일상 작업에는 거의 안 쓰지만, 있다는 것은 알아둘 것.

| 속성 | 하는 일 | 알아둘 것 |
|---|---|---|
| `Rotate` | 도형을 회전 | 글자와 같은 규칙이라면 **+가 반시계, −가 시계 방향**이다. 매뉴얼이 도형 쪽에는 부호를 안 적었다[추론] |
| `Flip Vert / Horz` | 상하·좌우 뒤집기 | 글자·이미지 객체도 같은 동작이다[원본 p.89] |
| `Gradation(그러데이션)` | 색을 단색 대신 그러데이션으로 | 선형·원형·다이아몬드·방추형 네 가지다. 미리보기 창에서 마우스로 끌어 방향과 길이를 정한다[원본 p.91] |
| `Texture Mapping` | 도형에 이미지를 입힌다 | `Fit`을 켜면 이미지가 도형 크기에 맞게 조정된다[원본 p.92] |

## 관련

- 글자 폭·크기를 줄이는 순서 → [글자 속성](/docs/nabi-cg/text-attributes)
- 여러 도형을 한꺼번에 같은 속성으로 → `객체 편집`의 속성 일괄 지정(`Ctrl+B`)
- 같은 서식을 저장해 두고 재사용 → `Style Catalog`
