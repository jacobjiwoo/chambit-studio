나비CG는 도형·글자·이미지 **객체**로 이루어지고, 객체의 속성을 바꾸려면 먼저 그 객체를 골라야 한다.[원본 p.25] 고른 다음에 하는 일은 대부분 아래쪽 `Attributes` 탭이 아니라 **`편집` 메뉴와 단축키**에 있다.[추론]

## 여러 개를 한 번에 고르기

하나는 마우스 왼쪽 버튼으로 누른다.[원본 p.25] 레이어창에서 그 레이어를 눌러도 같다.[원본 p.25]
여러 개를 고르는 길은 작업창과 레이어창 둘이다.[원본 p.25] 어느 쪽으로 갈지는 **객체가 겹쳐
있느냐**로 갈린다.[운영]

### 1. 작업창에서 — `Shift`

`Shift`를 누른 상태에서 객체들을 고른다.[원본 p.25]

- 페이지 안의 모든 객체는 `Ctrl+A`다[원본 p.25]
- `Ctrl`이나 `Shift`로 이미 고른 객체를 다시 누르면 선택이 풀린다[원본 p.27]
- **`Ctrl`을 누른 채 끌면 복사가 된다** — 약간이라도 움직이면 복사되므로 주의해서 쓴다[원본 p.27]
- 그래서 여러 개를 고르는 데는 `Shift` 쪽이 안전하다[운영]

### 2. 레이어창에서 — `Ctrl` / `Shift`

`Ctrl`을 누른 채 원하는 레이어들을 고른다.[원본 p.25] 붙어 있는 레이어를 통째로 잡을 때는 첫
레이어를 고른 뒤 `Shift`를 누르고 마지막 레이어를 누른다.[원본 p.25]

**자막이 배경판 위에 겹쳐 있어 작업창에서 원하는 것이 안 집힐 때 이쪽으로 온다.**[추론]

### 기준이 되는 객체 — 마지막에 고른 것

아래의 정렬도 크기 맞추기도 **마지막에 고른 객체**를 기준으로 한다.[원본 p.27] 기준 객체 둘레에는
노란색 컨트롤 포인트 8개가 생긴다.[원본 p.27] 어느 것이 기준인지는 화면에서 그걸로 안다.[추론]

- 마우스로 영역을 끌어 고르면 **마지막에 만든 객체**가 기준이 된다[원본 p.27]
- 골라 둔 것들 안에서 기준만 바꾸려면 아무 키도 누르지 않은 채 그 객체를 누른다[원본 p.27]

## 자막 여러 장의 서체를 한꺼번에 바꿀 때 — 속성 일괄 지정

**페이지를 한 장씩 열어 고치지 않아도 된다.**[운영] 설교 한 편의 자막을 앉혀 놓고 서체나 크기를
잘못 잡은 것을 뒤늦게 알면 그 페이지 전부를 다시 여는 일이 된다 —
[텍스트 임포트](/docs/nabi-cg/text-import)에서 *"서체를 먼저 정한다"*가 비싼 단계인 이유가
이것이고, 늦었을 때의 길이 여기다.[운영]

**이 기능을 안 써도 자막은 매주 나간다. 그래서 있는 줄 모른 채 지나가기 쉬운 자리다.**[운영]

셋이 있고 **한 번에 바뀌는 범위가 다르다.**[원본 p.30] 위에서부터 시도하고, 그걸로 안 되면
다음으로 내려간다 — 아래로 갈수록 안 건드려도 될 것까지 함께 바뀐다.[운영]

### 1. 값 하나만 바꾼다 — `Ctrl+B` 객체 속성 일괄 지정

여러 페이지의 객체 속성을 한 번에 골라 바꾸는 기능이다.[원본 p.29]

1. 바꿀 페이지들을 페이지 리스트에서 고른다 — 연속은 `Shift`, 띄엄띄엄은 `Ctrl`이다[원본 p.29]
2. `편집 > 객체속성 일괄지정`을 체크한다(`Ctrl+B`)[원본 p.29]
3. `Attributes` 탭의 값을 바꾸면 고른 페이지에 함께 걸린다[원본 p.29]

- **같은 종류에만 걸린다** — 글자 객체의 속성을 바꾸면 글자 객체만, 도형 객체를 바꾸면 도형 객체만 바뀐다[원본 p.29]
- 작업창에서 객체의 외곽 포인터로 크기나 위치를 조정하면 배경이미지와 애니메이션을 뺀 **모든** 객체가 함께 조절된다[원본 p.29]
- 체크가 켜져 있는 동안은 바꾸는 값마다 계속 걸린다.[원본 p.30] 끝나면 다시 눌러 끄는 편이 낫다[운영]

### 2. 페이지마다 같은 줄만 바꾼다 — `Ctrl+Shift+B`

고른 페이지들에서 **같은 순서에 있는 글자 객체 레이어**의 서체·색상·크기를 한 번에 바꾼다.[원본 p.30]
고른 모든 페이지에서 둘째 글자 객체 레이어에만 지금 속성을 걸고 싶을 때 쓴다.[원본 p.30]

1. 바꿀 페이지들을 페이지 리스트에서 고른다[원본 p.30]
2. 바꿀 글자 객체 레이어를 골라 속성을 바꾼다[원본 p.30]
3. `편집 > 같은 순서의 레이어 객체들에만 현재 속성 적용`을 누른다[원본 p.30]

### 3. 통째로 같게 만든다 — `Ctrl+Alt+B`

지금 고른 객체의 속성을 고른 페이지의 **모든 객체**에 건다 — 서체·색상·크기에 **위치까지**
따라간다.[원본 p.29] 고른 객체가 없으면 마지막에 고른 객체의 속성이 기준이 된다.[원본 p.29]

매뉴얼이 둘을 갈라 준다 — 일부만 바꾸려면 `Ctrl+B`, 글자 객체의 속성을 완전히 일치시키려면
이쪽이다.[원본 p.29] 자리를 따로 잡아 둔 페이지가 섞여 있으면 그 자리까지 밀린다.[추론] 그래서
셋 중 마지막에 쓴다.[운영]

| 메뉴 | 단축키 | 무엇이 기준인가 | 어디에 걸리는가 |
|---|---|---|---|
| `객체속성일괄지정` | `Ctrl+B` | 체크가 켜진 동안 바꾸는 값마다[원본 p.30] | 고른 페이지 안의 같은 객체[원본 p.30] |
| `같은 순서의 레이어 객체들에만 현재 속성 적용` | `Ctrl+Shift+B` | 지금 고른 객체의 속성[원본 p.30] | 고른 페이지 안의 같은 순서 레이어 객체[원본 p.30] |
| `모든 객체를 현재 속성으로 변경` | `Ctrl+Alt+B` | 지금 고른 객체의 속성[원본 p.30] | 고른 페이지의 모든 객체 — 위치까지 따라간다[원본 p.29] |

## 배경판과 자막을 같은 크기·같은 줄에 맞출 때

### 크기 맞추기 — 기준 객체에 맞춘다

골라 둔 객체들의 크기를 기준 객체에 맞춘다.[원본 p.27] 가로만, 세로만, 가로+세로 중에
고른다.[원본 p.27] **도형과 이미지 객체만 된다.**[원본 p.27]

- 배경판 여러 개를 눈으로 비슷하게 맞추던 자리다[운영]
- 글자 객체는 여기서 안 되므로 크기는 [글자 속성](/docs/nabi-cg/text-attributes)에서 따로 잡는다[추론]
- 이건 한 페이지 안의 일이다.[추론] 페이지를 건너 크기를 옮기는 것은 위의 `Ctrl+B`다[추론]

### 정렬 — 무엇에 맞출지 셋 중에 고른다

객체의 위치·크기·정렬순서를 세 가지 기준으로 맞출 수 있다.[원본 p.26]

- `Safe Area(안내선)` 기준[원본 p.26] — 화면 가장자리에서 안쪽으로 잡아 둔 영역이다[추론]
- 정렬선 기준[원본 p.26]
- 마지막에 고른 객체 기준[원본 p.26]

각 메뉴 옆 `▼`를 누르면 맞출 위치를 고른다.[원본 p.26] 위·가운데·아래와 왼쪽·가운데·오른쪽의
조합이다.[원본 p.27]

## 편집 중에 다른 객체가 자꾸 잡힐 때

### 위치 고정 — `Alt+L`

객체를 고르고 `Alt+L`을 누르면 위치가 고정된다.[원본 p.30] 고정된 객체는 마우스로는 못
움직이지만 키보드로는 움직여지고, 색이나 크기 같은 속성 값은 그대로 바꿀 수 있다(크기 변경은 글자
객체만 된다).[원본 p.30] 고정된 객체는 작업창에 회색 선으로 표시된다.[원본 p.30]

- 페이지 안의 위치 고정을 한 번에 풀려면 `Ctrl+U`다[원본 p.31]
- **배경판을 고정해 두고 글자만 만지면 배경판을 실수로 끌고 다니는 일이 없다**[운영]

### 락 — 선택 자체가 안 되게

락은 타임 라인에 자물쇠로 지정된 것이고, 락이 걸린 객체는 작업창에서 선택이 안 되는 상태가
된다.[원본 p.31] 편집 중에 마우스에 자꾸 잡혀 방해되는 객체에 쓴다.[원본 p.31] 한 번에 풀려면
`Ctrl+Shift+U`다.[원본 p.31]

## 나머지 속성

일상 작업에는 거의 안 쓰지만, 있다는 것은 알아둘 것.

| 항목 | 하는 일 | 알아둘 것 |
|---|---|---|
| 잘라내기 `Ctrl+X` / 붙이기 `Ctrl+V` | 객체를 다른 페이지로 옮긴다 | 붙이면 원래 있던 자리와 같은 위치에 붙는다[원본 p.26] |
| 복사 `Ctrl+C` | 같은 객체를 하나 더 | 한 페이지 안에서는 `Ctrl`+드래그, 수직·수평으로 복사할 때는 `Ctrl+Shift`+드래그다[원본 p.26] |
| 키보드 이동 `Ctrl+방향키` / `Alt+방향키` | 조금씩 밀어 옮긴다 | 간격은 옵션에서 정하고 `Alt` 쪽이 그 값의 10배씩 움직인다[원본 p.26] |
| 마우스 크기 조정 | 객체를 고르면 생기는 조절 상자 8개를 끈다[원본 p.26] | 숫자로 넣는 쪽은 [도형 속성](/docs/nabi-cg/shape-attributes)의 `Height`·`Width`다[추론] |
| 순서 `Ctrl+Shift+↑` `↓` `→` `←` | 앞뒤 순서를 바꾼다 | 차례로 맨 위로 · 맨 아래로 · 위로 · 아래로다[원본 p.28] |
| `Undo/Redo(작업취소·다시실행)` | `Ctrl+Z` / `Ctrl+Y` | 각 20단계까지다. 페이지 사이의 잘라내기·붙이기도 되돌려진다[원본 p.28] |
| 삭제 | 도형·이미지는 `Del` | 글자 객체만 `Shift+Del`이다[원본 p.28] |
| 그룹 `Ctrl+G` | 글자·도형·이미지를 묶어서 처리한다[원본 p.28] | 묶이면 빨간색 점선으로 표시되고 이동·복사·삭제가 한 번에 된다[원본 p.29] |
| `페이지 리스트 업데이트` | 일괄 지정한 결과를 페이지 리스트에서 바로 확인 | 끄면 첫 페이지만 보인다. 켜면 메모리를 쓰므로 페이지가 많거나 PC 사양이 낮으면 느려질 수 있다[원본 p.30] |
