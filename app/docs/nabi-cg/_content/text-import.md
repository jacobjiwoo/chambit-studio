`삽입 > 텍스트 파일`, 단축키는 `Ctrl+T`다.[원본 p.110] txt로 저장한 문서 파일을 읽어 들이거나
윈도우에서 복사한 텍스트를 바로 쓴다.[원본 p.49] 원고 한 장이 자막 페이지 여러 장으로 갈려
들어간다.[원본 p.50]

## 원고 txt를 자막 페이지로 앉히기

매주 설교 자막을 만드는 길이 이것이다.[운영] **넣을 txt를 손으로 만들지 않아도 된다** — 설교
원고 hwp를 [설교 자막 추출기](/subtitle-extractor)에 넣으면 자막 한 장이 빈 줄 하나로 갈린
txt가 그대로 나온다.[운영] 그 빈 줄이 아래 `빈 줄` 페이지 넘김 설정과 맞는다.[운영]

### 1. 서체와 자리를 먼저 정한다

**불러오기 전에 정한다.**[원본 p.50] 서체의 종류와 색, 그리고 글자가 앉을 자리 셋이다.[원본 p.50]
자리는 편집창의 가로·세로 기준 영역을 마우스로 끌어 잡는다.[원본 p.50]

여기서 정한 값이 불러온 페이지 전부에 걸린다.[추론] 뒤늦게 서체를 바꾸면 페이지를 하나씩 손대게
되므로 이 단계가 가장 비싸다.[추론] 매주 같은 값을 다시 맞추고 있다면
[Style Catalog](/docs/nabi-cg/style-catalog)에 한 번 등록해 두는 편이 낫다.[운영]

### 2. 페이지가 어디서 넘어갈지 정한다

`페이지 넘김 설정`에서 고르고 `적용`을 누른다.[원본 p.50]

- `빈 줄` — 원고의 빈 줄에서 다음 페이지로 넘어간다[원본 p.50]
- `지정 줄 수` — 정해 둔 줄 수마다 넘어간다[원본 p.50]

빈 줄 대신 `//`를 쓸 수도 있다.[원본 p.51] 둘 중 어느 쪽을 쓸지는 `도구 > 옵션 > General`의
`Use "//" as Page Delimiter When Import Text`가 정한다.[원본 p.51]

한 줄이 기준 영역보다 가로로 길 때 다음 줄로 내릴지는 `다음 줄로 넘김`에서 정한다.[원본 p.51]

### 3. `텍스트 삽입`을 누른다

항목을 다 정하고 `텍스트 삽입`을 누르면 설정값대로 들어간다.[원본 p.51]

## 불러왔는데 페이지 리스트가 비어 보일 때

**정상이다.**[원본 p.50] 읽어 들인 페이지가 왼쪽 페이지 리스트에 한꺼번에 다 나타나지는 않고,
각 페이지를 눌러야 나타난다.[원본 p.50]

`페이지 리스트 업데이트`를 켜면 삽입과 동시에 보인다.[원본 p.50] 다만 시스템 메모리를 쓰므로
페이지 수가 많거나 PC 사양이 낮으면 처리가 느려질 수 있다.[원본 p.50]

## 원고 안에서 정렬을 지시하기 — 정렬 제어문자

원고 txt에 기호를 한 줄 넣어 두면 그 정렬로 들어온다.[원본 p.51] 제어문자는 **별개의 줄에
단독으로** 쓴다.[원본 p.51] 새 페이지 구분을 뺀 나머지는 **문서 첫 줄에 한 번만** 적으면
된다.[원본 p.51]

| 제어문자 | 하는 일 |
|---|---|
| 빈 줄 | 새 페이지로 넘김[원본 p.51] |
| `//` | 새 페이지로 넘김[원본 p.51] |
| `<<` | 정렬선 기준 왼쪽 정렬[원본 p.51] |
| `>>` | 정렬선 기준 오른쪽 정렬[원본 p.51] |
| `<>` | 정렬선 기준 가운데 정렬[원본 p.51] |
| `&&` | 영화자막 정렬 — 페이지 안에서 가장 긴 문장을 가운데에 놓고 나머지를 그 왼쪽에 맞춘다[원본 p.51] |

제어문자를 하나도 안 쓰면 [글자 속성](/docs/nabi-cg/text-attributes)의 정렬 값이 그대로
적용된다.[원본 p.51] 설교 자막은 대개 가운데 정렬 하나로 끝난다.[운영]

## 다른 창에서 복사한 문장을 바로 붙일 때 — Windows Clip(클립보드 붙여넣기)

파일로 저장하지 않고 클립보드에 복사한 문자열을 그대로 붙일 수 있다.[원본 p.53] 광고 문구
한두 줄처럼 원고 파일을 만들 것도 없는 자리에 쓴다.[운영]

붙인 글자가 네모 박스로 보이면 서체가 그 언어를 못 그리는 것이다.[원본 p.53] 해당 언어의
트루타입 서체나 `Tahoma`로 바꾸면 정상으로 보인다.[원본 p.53]

## 나머지 속성

일상 작업에는 거의 안 쓰지만, 있다는 것은 알아둘 것.

| 항목 | 하는 일 | 알아둘 것 |
|---|---|---|
| `크롤 타입` | 불러온 페이지 전체를 크롤 페이지로 지정 | 흐르는 자막으로 통째로 들어간다[원본 p.51] |
| `템플릿` | 미리 만들어 둔 템플릿을 골라 적용 | 더블클릭하면 그 템플릿이 적용된다. 지금 편집화면을 템플릿에 추가하거나 템플릿으로 삼을 수도 있다[원본 p.51] |
| 템플릿 저장 위치 | `C:\Compix\Nabi\TEMPLATES\TextImport`[원본 p.51] | 여기 없는 템플릿은 목록에 안 뜬다[추론] |
| `제목/내용 폰트 변경` | Alias로 지정된 내용의 서체를 바꾼다 | 교회DB를 쓸 때의 항목이다 — [이 문서가 다루지 않는 것](/docs/nabi-cg/not-covered)[원본 p.51] |
| 조각그림이 있는 페이지 | 불러온 페이지마다 같은 조각그림이 복사된다[원본 p.50] | 딸려 오는 것이 싫으면 빈 페이지에서 불러온다[추론] |
