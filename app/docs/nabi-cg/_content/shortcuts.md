나비CG의 단축키를 메뉴 갈래별로 한 장에 모았다.[운영] 매뉴얼 `Ch2 §7` 표를 메뉴와 키 두 열로 옮겼다.[운영]
훑어 내려가며 찾는 표라 쪼개지 않는다.[운영] 대부분이 편집할 때 쓰는 키이고, 송출 키는 키패드 몇 개뿐이다.[운영]

## 매뉴얼이 나온 뒤 생긴 키

매뉴얼이 마지막으로 고쳐진 뒤 compix 변경 이력에 `창` 메뉴 단축키 셋이
올라왔다.[운영] 방송실 PC 화면에서 이름과 동작을 아직 확인하지 않은 줄이다.[운영]

| 메뉴 | 단축키 |
|---|---|
| Reset Layout — 창 배치를 처음으로 되돌린다 | `Ctrl+Shift+F5`[추론] |
| Playback Resource Browser (PageList Window) | `Ctrl+Shift+F9`[추론] |
| 창 › File Browser (PageList Window) — 페이지 리스트 창의 File Browser를 켜고 끈다 | `Ctrl+Shift+F8`[추론] |

## 매뉴얼이 엇갈리는 자리

- `Alt+P`가 삽입의 `그림 변경`에 붙어 있고[원본 p.110] 송출의 `프롬프터 송출 On/Off`에도 붙어 있다[원본 p.111]
- 둘 중 무엇이 먹는지는 화면에서 눌러 봐야 안다[추론]
- `프롬프터 설정`은 이 표에서 `Alt+Shift+P`인데[원본 p.111] 본문 절 제목에는 `Ctrl+Shift+P`로 적혀 있다[원본 p.62]
