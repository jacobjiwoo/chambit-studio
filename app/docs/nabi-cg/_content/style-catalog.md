`Style Catalog(스타일 모음)`은 나비CG 화면을 이루는 여덟 영역 중 하나다.[원본 p.2] 자주 쓰는
글자·색상·이미지·동영상 서식을 **스타일**로 저장해 두고 편집 중에 바로 적용한다.[원본 p.2]
화면에 안 보인다면 창 배치가 틀어진 것인데, 되돌리는 방법은 이 문서에 아직 없다 —
[이 문서가 다루지 않는 것](/docs/nabi-cg/not-covered)에 적어 뒀다.[운영]

## 매주 같은 서식을 다시 맞추지 않으려면

설교 자막은 매주 같은 서체·크기·색으로 나간다.[운영] 한 번 잘 맞춘 객체를 스타일로 등록해
두면 다음 주에는 **끌어다 놓는 것으로 끝난다.**[운영]

### 1. 잘 맞춘 객체를 등록한다

- 글자·도형 — 객체를 고르고 `Ctrl+Alt+A`[원본 p.109]
- 페이지 통째로 — 저장할 페이지에서 `Ctrl+Alt+P`[원본 p.109]
- 색 — `Attributes` 탭의 색을 Catalog로 끌어다 놓는다[원본 p.37]

`Char(글자)`는 텍스트 객체의 서체·크기·색을 **함께** 저장한다.[원본 p.37] 크기까지 딸려 오므로
자막 한 줄 길이가 매주 비슷하다면 이 하나로 끝난다.[추론]

### 2. 다음 주에는 끌어다 놓는다

등록해 둔 스타일을 작업창의 객체 위로 끌어다 놓으면 그 서식이 적용된다.[원본 p.36]

| Style | 저장하는 것 | 끌어다 놓는 자리 |
|---|---|---|
| `Char(글자)` | 텍스트 객체의 서체·크기·색[원본 p.37] | 바꿀 텍스트 객체 위[원본 p.37] |
| `Color(색)` | 색 하나[원본 p.37] | 객체 위에 놓으면 `Face`만 바뀌고, `Attributes` 탭의 `F`/`E`/`S`에 놓으면 그 자리에 들어간다[원본 p.37] |
| `Shape(도형)` | 도형 객체의 모양·크기·색[원본 p.37] | 작업창에 놓으면 그 도형이 **새로 하나 생긴다**[원본 p.37] |
| `Page(페이지)` | 작업 중인 페이지 통째로[원본 p.37] | 작업창에 놓으면 지금 페이지가 **그 페이지로 바뀐다**[원본 p.37] |

`F`·`E`·`S`는 면(`Face`)·테두리(`Edge`)·그림자(`Shadow`)다.[추론]

**`Shape`와 `Page`는 놓는 순간 객체가 생기거나 페이지가 갈린다.**[추론] 서식만 바꾸려던
것이었다면 `Ctrl+Z`로 되돌린다.[추론]

## 여러 페이지에 같은 틀을 한꺼번에 씌우기

`Page` 스타일은 한 장씩 바꾸는 것 말고 **여러 페이지에 일괄 지정**도 된다.[원본 p.35] 페이지를
여러 장 고른 뒤 `Style Catalog`의 `Page`에서 원하는 템플릿을 더블클릭하거나 끌어다 놓는다.[원본 p.35]

- **글자 객체에만 걸린다**[원본 p.35]
- 템플릿에 있는 글자 객체 수만큼만 적용되고 나머지 객체는 그대로 남는다[원본 p.35]
- 위에 있는 객체부터 순서대로 짝지어지고, 같은 높이면 왼쪽 것이 먼저다[원본 p.35]

원고를 통째로 임포트한 뒤 페이지 서식이 제각각일 때 한 번에 정리하는 길이다.[운영]

## 내 스타일만 모아 파일로 저장하기

등록한 스타일은 용도별로 갈라 파일로 저장할 수 있다.[원본 p.37] 스타일 이름 위에서 마우스
오른쪽 버튼을 누르면 `New`가 나오고, 그렇게 만든 빈 자리에 스타일을 추가하면 저장 창이
뜬다.[원본 p.37] 확장자는 `.nbs`다.[원본 p.37]

`Image`·`Back`·`Animation`처럼 폴더를 링크해 쓰는 스타일은 저장 대상이 아니다.[원본 p.37]

**설교용과 광고용을 다른 파일로 갈라 두면 목록이 짧아진다.**[운영]

## 나머지 속성

일상 작업에는 거의 안 쓰지만, 있다는 것은 알아둘 것.

| 항목 | 하는 일 | 알아둘 것 |
|---|---|---|
| `Image` · `Back` | 이미지 폴더를 등록해 두고 꺼내 쓴다 | 작업창에 놓으면 이미지 객체 또는 배경이미지로 들어간다. tga·bmp·jpg·gif·png·tif[원본 p.37] |
| `Animation` · `Video` · `Back Video` | 애니메이션·동영상 폴더를 등록해 두고 꺼내 쓴다 | 작업창에 놓으면 각각 애니메이션·동영상·배경동영상으로 들어간다[원본 p.37] |
| `Add Folder` | 등록할 PC 폴더를 지정한다 | 폴더를 쓰는 스타일에서만 눌린다. 폴더의 이미지 용량이 크면 로딩이 느려질 수 있다[원본 p.39] |
| `Refresh` | 폴더 내용이 바뀌었을 때 다시 읽는다 | `Image`·`Back`·`Animation`에서만 눌린다[원본 p.39] |
| `View` · `Icon` | 썸네일 보는 방식을 바꾼다 | 여러 방식으로 볼 수 있다[원본 p.39] |
| 복사 · 붙이기 · 삭제 | 등록한 스타일을 정리한다 | 스타일을 고르고 마우스 오른쪽 버튼[원본 p.38] |
| 관련 옵션 | `도구 > 옵션 > General`의 `Style Catalog with folder list` | 폴더를 쓰는 스타일에 걸린다[원본 p.36] |
| 관련 옵션 | `도구 > 옵션 > General`의 `Refresh thumbnail in style catalog when NABI starts` | `Refresh`에 걸린다[원본 p.39] |
