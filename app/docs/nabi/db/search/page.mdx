# 2. DB검색

## 2.1. 성경 책갈피

성경검색의 경우 분류의 빠른 검색을 위해 줄임말 입력 시 자동 완성기능을 제공한다.\
성경의 종류를 줄임말로 검색하고, 장, 절을 Tab키로 이동하면서 숫자를 입력하면 빠르게 검색할 수 있다.

## 2.2. 검색

찬송가와 교독문의 경우는 장으로 검색하거나 제목, 가사의 내용으로 검색이 가능하다.

![찬송가 탭에서 제목 ‘사랑’으로 검색한 결과](/docs/nabi/images/db-search-01.png)

## 2.3. DB편집

검색한 DB내용을 수정할 경우 사용한다.\
검색된 내용 중 수정이 필요할 경우 “DB편집”버튼을 누르고, 하단에 검색된 내용을 더블 클릭하면 아래와 같이 수정이 가능한 상태가 된다. 원하는 내용으로 변경하고 Enter 키를 눌러 적용하면 수정된 내용이 반영된다.

![DB 편집 상태에서 검색 결과 한 줄을 수정하는 화면](/docs/nabi/images/db-search-02.png)
