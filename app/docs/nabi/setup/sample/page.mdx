## 1.1. 화면 구성

단축키는 `「Ctrl+N」`처럼 낫표로 적는다. **굵은 글씨 소제목**도 여기서 본다.

| 항목 | 설명 |
| - | - |
| 송출 | 프로그램 화면으로 내보낸다 |
| 미리보기 | 송출 전에 본다 |
