# 지침 파일 작성 규칙

`CLAUDE.md`, `.claude/rules/`, `skills/`, `agents/`처럼 에이전트가 읽는 파일을 쓸 때 따른다. 근거는 [조사 노트](../../.scratch/language-rule/research/examples-in-agent-instructions.md)다.

## 쓰기 전에 순서대로 묻는다

1. lint, hook, 스크립트로 강제할 수 있나? 그렇다면 글로 쓰지 않고 그쪽에서 강제한다.
2. Claude가 이미 기본으로 하는가? 그렇다면 쓰지 않는다.
3. 규칙 문장만으로 판단이 갈리는 경계가 있나? 있을 때만 예시를 넣는다.
4. 예시가 코드인가? 그렇다면 복사하지 않고 실제 파일을 가리킨다.
5. 매 세션 읽히는 파일인데 일부 경우에만 필요한가? 그렇다면 `paths`를 단 rule이나 skill로 뺀다.

## 예시를 넣을 때

- 규칙 문장을 먼저 쓰고 예시는 그 아래에 둔다. 예시가 보여 주는 것은 규칙 문장에도 적는다.
- 3–5개 안쪽으로, 서로 다른 경우를 하나씩 고른다. 같은 종류를 늘어놓지 않는다.
- 금지형 예시는 실제로 나온 실수만 쓰고, 쓰는 형태와 짝지어 둔다.
- 같은 실수가 반복될 때만 예시를 더한다. 실수 한 번으로 늘리지 않는다.
