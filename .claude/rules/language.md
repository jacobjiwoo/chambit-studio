# 언어 규칙

사람이든 에이전트든 따른다.

## 한국어로 쓴다

채팅 응답, 문서(`docs/`, `.scratch/`, `README.md`), `.claude/`의 규칙·skill 본문, 커밋 메시지, PR 제목과 본문, 코드 주석은 한국어로 쓴다.

## 영어로 둔다

코드 식별자, 파일·폴더 이름, 브랜치 이름([branching.md](branching.md))은 영어다.

## 용어는 번역하지 않는다

고유명사와 업계 용어는 원어로 쓴다. 한글 음차가 이미 굳은 말은 음차로 쓴다. 번역어를 새로 만들지 않는다. 애매하면 원어로 둔다.

| 원어 | 쓰는 형태 | 쓰지 않는 형태 |
| - | - | - |
| Pull Request | Pull Request | 당김 요청 |
| commit, branch | 커밋, 브랜치 | — |
| context window | context window | — |
| Next.js, App Router | Next.js, App Router | — |

- "쓰지 않는 형태"에는 실제로 나온 실수만 적는다.
- 행은 같은 실수가 반복될 때만 더하고, 5행을 넘기지 않는다.

## 원문은 그대로 둔다

에러 메시지·로그·명령 출력, 외부 문서 인용, 명령어·코드·설정 키는 번역하지 않는다.

## 문체

문서, 커밋, PR은 "~한다"체로 쓴다. 채팅은 해요체로 쓴다.

## 범위 밖

앱이 사용자에게 보여 주는 UI 문구는 이 규칙이 다루지 않는다.
